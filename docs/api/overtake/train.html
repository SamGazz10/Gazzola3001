overtake.train

Train the overtake-probability network and evaluate it against the alternatives.

python -m overtake.train                         # train on simulated attempts
python -m overtake.train --data attempts.csv     # train on your own labelled attempts

A CSV needs every column in overtake.features.FEATURES plus an overtake column (1 if the move stuck, 0 if not). By default the trained ensemble is written to models/overtake_net.pt, the test metrics to reports/results/test_metrics.json and the training-curve, calibration and what-if figures to reports/figures/.

Data are split 80/10/10 into training, validation and test sets. The validation set is used for early stopping and the learning-rate schedule (and, in overtake.experiments, for choosing the architecture); the test set is used only once, for the final numbers.

 42def load_data(path=None, samples=300_000, seed=0):
 43    """Read labelled attempts from a CSV, or simulate them.
 44
 45    Parameters
 46    ----------
 47    path : str or pathlib.Path, optional
 48        CSV of labelled attempts: every `overtake.features.FEATURES` column
 49        plus a 0/1 ``overtake`` label. Omit to simulate.
 50    samples : int, optional
 51        Attempts to simulate (300,000); ignored when ``path`` is given.
 52    seed : int, optional
 53        Seed for the simulated scenarios and outcomes; ignored when ``path``
 54        is given.
 55
 56    Returns
 57    -------
 58    pandas.DataFrame
 59        One row per attempt: the schema columns and ``overtake``. Simulated
 60        data also has ``p_true``, the exact probability from quadrature (for
 61        validation only, never a model input). Extra CSV columns are kept.
 62
 63    Raises
 64    ------
 65    FileNotFoundError
 66        If there is no file at ``path`` (from `pandas.read_csv`).
 67    ValueError
 68        If the CSV is missing columns, has values outside the schema (see
 69        `overtake.features.validate`), or has labels other than 0/1.
 70    """
 71    if path is None:
 72        return simulator.generate_dataset(samples, seed=seed)
 73    df = pd.read_csv(path)
 74    validate(df)
 75    if LABEL not in df or not df[LABEL].isin([0, 1]).all():
 76        raise ValueError(f"{path}: needs an '{LABEL}' column of 0/1 values")
 77    return df

 80def split(df, seed=0):
 81    """Shuffle the rows and split them into training (80 %), validation (10 %) and test (10 %) sets.
 82
 83    Parameters
 84    ----------
 85    df : pandas.DataFrame
 86        Labelled attempts, one per row.
 87    seed : int, optional
 88        Seeds the shuffle; the same seed always gives the same split.
 89
 90    Returns
 91    -------
 92    train_df, val_df, test_df : pandas.DataFrame
 93        Validation and test get ``len(df) // 10`` rows each (30,000 of
 94        300,000); training gets the rest (80 %, plus the remainder when
 95        ``len(df)`` is not a multiple of 10). With fewer than 10 rows the
 96        validation and test sets are empty. Rows keep their original index.
 97    """
 98    idx = np.random.default_rng(seed).permutation(len(df))
 99    n = len(df) // 10
100    # Validation and test are the first two tenths of the shuffled order; training keeps the rest.
101    return df.iloc[idx[2 * n:]], df.iloc[idx[:n]], df.iloc[idx[n:2 * n]]

104def train_network(train_df, val_df, hidden=HIDDEN, dropout=0.1, epochs=100, batch_size=1024, lr=2e-3,
105                  patience=5, seed=0, physics_features=False, log=print):
106    """Train an `OvertakeNet` with binary cross-entropy and early stopping.
107
108    Parameters
109    ----------
110    train_df, val_df : pandas.DataFrame
111        Training and validation attempts: the schema columns plus the 0/1
112        ``overtake`` label. Both must be non-empty.
113    hidden : tuple of int, optional
114        Hidden layer widths (`HIDDEN` = (64, 64)).
115    dropout : float, optional
116        Probability of zeroing each hidden unit during training (0.1); off
117        at prediction.
118    epochs : int, optional
119        Maximum number of passes over the training data (100); must be at
120        least 1.
121    batch_size : int, optional
122        Attempts per AdamW step (1,024; the last batch of an epoch may be
123        smaller).
124    lr : float, optional
125        Initial AdamW learning rate (2e-3). ``ReduceLROnPlateau`` halves it
126        after 3 consecutive epochs in which the validation loss fails to fall
127        by more than 0.01 % of its best value (``patience=2`` is the number of
128        such epochs tolerated before it acts), and again after every further
129        3 such epochs.
130    patience : int, optional
131        Stop after this many consecutive epochs (5) in which the validation
132        loss does not fall more than 1e-5 below its best. The best weights
133        are restored whether or not training stops early.
134    seed : int, optional
135        Seeds weight initialisation, dropout and batch order, so runs are
136        repeatable.
137    physics_features : bool, optional
138        Include the derived energy-cover inputs (`overtake.features.DERIVED`);
139        off in the final model (see `overtake.experiments.ablation`).
140    log : callable, optional
141        Receives one progress line per epoch, plus one more if early
142        stopping ends training.
143
144    Returns
145    -------
146    predictor : OvertakePredictor
147        The network from the best epoch (lowest validation loss, to within
148        the 1e-5 improvement threshold) and its fitted preprocessing.
149    history : list of dict
150        One dict per epoch run: ``epoch`` (from 1); ``train_loss`` (mean
151        binary cross-entropy over the epoch's batches, dropout on);
152        ``val_loss`` (binary cross-entropy on ``val_df`` after the epoch,
153        dropout off); ``seconds`` (wall-clock time of the epoch, validation
154        included).
155
156    Raises
157    ------
158    ValueError
159        If either table fails `overtake.features.validate`.
160    """
161    # Seeds the torch generator behind weight initialisation, dropout masks and the batch order.
162    torch.manual_seed(seed)
163    # Statistics from the training set only, so validation and test rows are scaled exactly like unseen data.
164    preprocessor = Preprocessor(physics_features=physics_features).fit(train_df)
165    x_cat, x_num = preprocessor.transform(train_df)
166    y = torch.tensor(train_df[LABEL].to_numpy(dtype=np.float32))
167    v_cat, v_num = preprocessor.transform(val_df)
168    v_y = torch.tensor(val_df[LABEL].to_numpy(dtype=np.float32))
169
170    model = OvertakeNet(hidden, dropout, preprocessor.n_inputs)
171    # AdamW (Loshchilov and Hutter) applies weight decay separately from the adaptive step. The
172    # learning rate, weight decay (1e-4), dropout and batch size are fixed starting values; the
173    # experiments in `overtake.experiments` do not tune them.
174    optimiser = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=1e-4)
175    # Halve the step size once validation loss has stalled for 3 epochs (patience=2 tolerated, the 3rd
176    # acts). PyTorch's default relative threshold (1e-4) decides what counts as a stall; early stopping
177    # below uses its own 1e-5 absolute test.
178    scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(optimiser, factor=0.5, patience=2)
179    # The network outputs logits. BCEWithLogitsLoss puts the sigmoid inside the loss in log-sum-exp
180    # form, so it stays exact for large |logit|. A separate sigmoid rounds to 1.0 in float32 (a logit
181    # of 20 already does), after which BCELoss can only return its clamp value of 100.
182    loss_fn = nn.BCEWithLogitsLoss()
183
184    history, best_loss, best_state, stale = [], float("inf"), None, 0
185    for epoch in range(1, epochs + 1):
186        start = time.perf_counter()
187        model.train()
188        # New random batch order every epoch, reproducible through torch.manual_seed above.
189        order = torch.randperm(len(y))
190        total = 0.0
191        for i in range(0, len(y), batch_size):
192            batch = order[i:i + batch_size]
193            optimiser.zero_grad()
194            loss = loss_fn(model(x_cat[batch], x_num[batch]), y[batch])
195            loss.backward()
196            optimiser.step()
197            # Weight by batch size: the last batch is smaller, so total / len(y) is the mean loss per attempt.
198            total += loss.item() * len(batch)
199        # Dropout off for validation; the whole validation set goes through in one pass.
200        model.eval()
201        with torch.no_grad():
202            val_loss = loss_fn(model(v_cat, v_num), v_y).item()
203        scheduler.step(val_loss)
204        seconds = time.perf_counter() - start
205        # train_loss is averaged over the epoch with dropout on while the weights are still changing,
206        # so it can sit above val_loss, especially in early epochs. That is expected.
207        history.append({"epoch": epoch, "train_loss": total / len(y), "val_loss": val_loss, "seconds": seconds})
208        log(f"epoch {epoch:3d}  train {total / len(y):.4f}  val {val_loss:.4f}  ({seconds:.1f}s)")
209
210        # Only a fall of more than 1e-5 counts as an improvement, so negligible changes in the
211        # loss do not reset the patience counter.
212        if val_loss < best_loss - 1e-5:
213            # deepcopy: state_dict() returns references to the live tensors, which later optimiser
214            # steps would overwrite.
215            best_loss, best_state, stale = val_loss, copy.deepcopy(model.state_dict()), 0
216        else:
217            stale += 1
218            if stale >= patience:
219                log(f"validation loss stopped improving; keeping epoch {epoch - stale}")
220                break
221    # Restore the best epoch's weights, whether the loop ended early or ran all the epochs.
222    model.load_state_dict(best_state)
223    return OvertakePredictor(model, preprocessor), history

226def train_ensemble(train_df, val_df, n_members=ENSEMBLE, seed=0, log=print, **kwargs):
227    """Train ``n_members`` networks with seeds ``seed, seed + 1, ...`` and average them.
228
229    Each member is trained exactly as by `train_network`; their predicted
230    probabilities are averaged, which reduces the run-to-run variation of a
231    single network.
232
233    Parameters
234    ----------
235    train_df, val_df : pandas.DataFrame
236        As for `train_network`; every member sees the same data.
237    n_members : int, optional
238        Number of networks (`ENSEMBLE` = 5); must be at least 1.
239    seed : int, optional
240        Member k (counting from 0) is trained with seed ``seed + k``.
241    log : callable, optional
242        Receives one line per member and the members' per-epoch lines.
243    **kwargs
244        Passed to `train_network` (for example ``epochs``, ``batch_size``,
245        ``lr``, ``hidden``).
246
247    Returns
248    -------
249    predictor : OvertakePredictor
250        All members, sharing one preprocessor (they see the same training data).
251    histories : list of list of dict
252        Each member's training history (see `train_network`).
253
254    Raises
255    ------
256    ValueError
257        If either table fails `overtake.features.validate`.
258
259    Examples
260    --------
261    >>> from overtake import simulator, train
262    >>> df = simulator.generate_dataset(20_000, seed=0)
263    >>> train_df, val_df, test_df = train.split(df)
264    >>> predictor, histories = train.train_ensemble(  # doctest: +SKIP
265    ...     train_df, val_df, n_members=2, log=lambda _: None)
266    >>> predictor.predict(test_df).shape  # doctest: +SKIP
267    (2000,)
268    """
269    members, histories = [], []
270    for k in range(n_members):
271        log(f"-- network {k + 1} of {n_members}")
272        predictor, history = train_network(train_df, val_df, seed=seed + k, log=log, **kwargs)
273        members.append(predictor)
274        histories.append(history)
275    # Every member fitted an identical Preprocessor on the same train_df (fit is deterministic),
276    # so the first one serves the whole ensemble.
277    return OvertakePredictor([m.model for m in members], members[0].preprocessor), histories

280def expected_calibration_error(y, p, bins=10):
281    """Expected calibration error (ECE, as in Guo et al. 2017) over equal-width probability bins.
282
283    Predictions are grouped into ``bins`` bins of width ``1 / bins``. The
284    result is the sum over non-empty bins of (share of predictions in the bin)
285    x |mean predicted probability - observed overtake rate|.
286
287    Parameters
288    ----------
289    y : numpy.ndarray, shape (n,)
290        Observed 0/1 outcomes.
291    p : numpy.ndarray, shape (n,)
292        Predicted probabilities in [0, 1].
293    bins : int, optional
294        Number of equal-width bins (10).
295
296    Returns
297    -------
298    float
299        ECE as a probability; 0 means perfectly calibrated (x 100 for
300        percentage points).
301    """
302    # np.digitize gives 1..bins for p in [0, 1) and bins + 1 for p == 1; shift to 0-based and fold
303    # p == 1 into the last bin.
304    idx = np.clip(np.digitize(p, np.linspace(0, 1, bins + 1)) - 1, 0, bins - 1)
305    # (idx == b).mean() is the bin's share of all predictions, the ECE weight.
306    return float(sum(abs(p[idx == b].mean() - y[idx == b].mean()) * (idx == b).mean()
307                     for b in range(bins) if (idx == b).any()))

310def metrics(y, p, p_true=None):
311    """Evaluation metrics for predicted probabilities.
312
313    Parameters
314    ----------
315    y : numpy.ndarray, shape (n,)
316        Observed 0/1 outcomes. It should contain both classes; otherwise
317        ``roc_auc`` is undefined (NaN with a warning on the installed
318        scikit-learn, a ``ValueError`` on older versions).
319    p : numpy.ndarray, shape (n,)
320        Predicted probabilities; clipped to [1e-7, 1 - 1e-7] before every
321        metric so log loss stays finite.
322    p_true : numpy.ndarray, shape (n,), optional
323        True probabilities (simulated data only).
324
325    Returns
326    -------
327    dict of str -> float
328        ``log_loss``, ``brier``, ``roc_auc``, ``accuracy`` (threshold 0.5),
329        ``calibration_error`` (`expected_calibration_error`, 10 bins) and,
330        with ``p_true``, ``mae_vs_true`` and ``max_error_vs_true``: the mean
331        and largest abs(p - p_true), as probabilities.
332    """
333    # Keep log loss finite if a model outputs exactly 0 or 1; moves p by at most 1e-7.
334    p = np.clip(p, 1e-7, 1 - 1e-7)
335    out = {
336        "log_loss": float(log_loss(y, p, labels=[0, 1])),
337        "brier": float(brier_score_loss(y, p)),
338        "roc_auc": float(roc_auc_score(y, p)),
339        "accuracy": float(((p >= 0.5) == y).mean()),
340        "calibration_error": expected_calibration_error(y, p),
341    }
342    if p_true is not None:
343        out["mae_vs_true"] = float(np.abs(p - p_true).mean())
344        out["max_error_vs_true"] = float(np.abs(p - p_true).max())
345    return out

348def main(argv=None):
349    """Command-line entry point: train the models, score them once on the test set and save the results.
350
351    Loads or simulates the attempts (`load_data`), splits them 80/10/10
352    (`split`), trains ``--ensemble`` networks (`train_ensemble`) and the
353    logistic-regression and gradient-boosting baselines on the training set,
354    then evaluates all three on the test set (`metrics`) and prints the
355    results as JSON.
356
357    Parameters
358    ----------
359    argv : list of str, optional
360        Command-line arguments without the program name; ``sys.argv[1:]`` if
361        omitted. See ``python -m overtake.train --help``.
362
363    Raises
364    ------
365    SystemExit
366        Status 2 if an option is malformed (argparse).
367    FileNotFoundError
368        If ``--data`` names a file that does not exist.
369    ValueError
370        If ``--data`` fails the schema or label checks (see `load_data`).
371
372    Notes
373    -----
374    Writes five files: ``--out`` (default ``models/overtake_net.pt``: weights,
375    preprocessing, test metrics, the first member's history and the total fit
376    time) and, under ``--reports`` (default ``reports/``),
377    ``results/test_metrics.json`` and ``figures/training_curve.png``,
378    ``figures/calibration.png`` and ``figures/what_if.png``. The README gives
379    about 4 minutes with the defaults.
380
381    Examples
382    --------
383    A quick run on 20,000 simulated attempts with a single network::
384
385        python -m overtake.train --samples 20000 --ensemble 1 --out tmp/net.pt --reports tmp/reports
386    """
387    parser = argparse.ArgumentParser(description=__doc__.split("\n")[0])
388    parser.add_argument("--data", type=Path, help="CSV of labelled attempts (default: simulate)")
389    parser.add_argument("--samples", type=int, default=300_000, help="simulated attempts to generate")
390    parser.add_argument("--epochs", type=int, default=100)
391    parser.add_argument("--batch-size", type=int, default=1024)
392    parser.add_argument("--lr", type=float, default=2e-3)
393    parser.add_argument("--seed", type=int, default=0)
394    parser.add_argument("--ensemble", type=int, default=ENSEMBLE, help="networks to train and average")
395    parser.add_argument("--out", type=Path, default=DEFAULT_MODEL)
396    parser.add_argument("--reports", type=Path, default=REPORTS)
397    args = parser.parse_args(argv)
398
399    start = time.perf_counter()
400    df = load_data(args.data, args.samples, args.seed)
401    print(f"{len(df):,} attempts ({time.perf_counter() - start:.0f}s); overtake rate {df[LABEL].mean():.1%}")
402    train_df, val_df, test_df = split(df, args.seed)
403
404    predictor, histories = train_ensemble(train_df, val_df, args.ensemble, seed=args.seed, epochs=args.epochs,
405                                          batch_size=args.batch_size, lr=args.lr)
406    logistic = baselines.logistic_regression().fit(train_df)
407    boosting = baselines.gradient_boosting(args.seed).fit(train_df)
408
409    y = test_df[LABEL].to_numpy()
410    # p_true (the exact quadrature probability) exists only for simulated data; a real CSV has no ground truth.
411    p_true = test_df["p_true"].to_numpy() if "p_true" in test_df else None
412    predictions = {"Neural network": predictor.predict(test_df),
413                   logistic.name: logistic.predict(test_df),
414                   boosting.name: boosting.predict(test_df)}
415    results = {"test_attempts": len(test_df),
416               "models": {name: metrics(y, p, p_true) for name, p in predictions.items()}}
417
418    # Total time of the epoch loops for all members; excludes data generation, baselines and plots.
419    fit_seconds = sum(h["seconds"] for history in histories for h in history)
420    # Only the first member's history is saved and plotted; the others stay in `histories`.
421    predictor.save(args.out, metrics=results, history=histories[0], fit_seconds=fit_seconds)
422    (args.reports / "figures").mkdir(parents=True, exist_ok=True)
423    (args.reports / "results").mkdir(parents=True, exist_ok=True)
424    (args.reports / "results" / "test_metrics.json").write_text(json.dumps(results, indent=2))
425    plots.training_curve(histories[0], args.reports / "figures" / "training_curve.png")
426    plots.calibration(y, predictions, args.reports / "figures" / "calibration.png")
427    # exact(scenarios) gives the true P(overtake) from the simulator's quadrature, which the what-if
428    # figure draws as dashed lines. A user CSV has no known truth, so the figure shows the network alone.
429    exact = (lambda s: simulator.probability(pd.DataFrame(s))) if args.data is None else None
430    plots.what_if(predictor.predict, args.reports / "figures" / "what_if.png", exact=exact)
431
432    print(json.dumps(results, indent=2))
433    print(f"saved model to {args.out} and results to {args.reports}/")
434

436if __name__ == "__main__":
437    main()

121        least 1.

124        smaller).

127        after 3 consecutive epochs in which the validation loss fails to fall
128        by more than 0.01 % of its best value (``patience=2`` is the number of
129        such epochs tolerated before it acts), and again after every further
130        3 such epochs.
131    patience : int, optional
132        Stop after this many consecutive epochs (5) in which the validation
133        loss does not fall more than 1e-5 below its best. The best weights
134        are restored whether or not training stops early.
135    seed : int, optional
136        Seeds weight initialisation, dropout and batch order, so runs are
137        repeatable.
138    physics_features : bool, optional
139        Include the derived energy-cover inputs (`overtake.features.DERIVED`);
140        off in the final model (see `overtake.experiments.ablation`).
141    log : callable, optional
142        Receives one progress line per epoch, plus one more if early
143        stopping ends training.
144
145    Returns
146    -------
147    predictor : OvertakePredictor

149        the 1e-5 improvement threshold) and its fitted preprocessing.
150    history : list of dict
151        One dict per epoch run: ``epoch`` (from 1); ``train_loss`` (mean
152        binary cross-entropy over the epoch's batches, dropout on);
153        ``val_loss`` (binary cross-entropy on ``val_df`` after the epoch,
154        dropout off); ``seconds`` (wall-clock time of the epoch, validation
155        included).
156

158    ------
159    ValueError
160        If either table fails `overtake.features.validate`.

162    # Seeds the torch generator behind weight initialisation, dropout masks and the batch order.
163    torch.manual_seed(seed)
164    # Statistics from the training set only, so validation and test rows are scaled exactly like unseen data.
165    preprocessor = Preprocessor(physics_features=physics_features).fit(train_df)
166    x_cat, x_num = preprocessor.transform(train_df)
167    y = torch.tensor(train_df[LABEL].to_numpy(dtype=np.float32))
168    v_cat, v_num = preprocessor.transform(val_df)
169    v_y = torch.tensor(val_df[LABEL].to_numpy(dtype=np.float32))
170
171    model = OvertakeNet(hidden, dropout, preprocessor.n_inputs)
172    # AdamW (Loshchilov and Hutter) applies weight decay separately from the adaptive step. The
173    # learning rate, weight decay (1e-4), dropout and batch size are fixed starting values; the
174    # experiments in `overtake.experiments` do not tune them.
175    optimiser = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=1e-4)
176    # Halve the step size once validation loss has stalled for 3 epochs (patience=2 tolerated, the 3rd
177    # acts). PyTorch's default relative threshold (1e-4) decides what counts as a stall; early stopping
178    # below uses its own 1e-5 absolute test.
179    scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(optimiser, factor=0.5, patience=2)
180    # The network outputs logits. BCEWithLogitsLoss puts the sigmoid inside the loss in log-sum-exp
181    # form, so it stays exact for large |logit|. A separate sigmoid rounds to 1.0 in float32 (a logit
182    # of 20 already does), after which BCELoss can only return its clamp value of 100.
183    loss_fn = nn.BCEWithLogitsLoss()
184
185    history, best_loss, best_state, stale = [], float("inf"), None, 0
186    for epoch in range(1, epochs + 1):
187        start = time.perf_counter()
188        model.train()
189        # New random batch order every epoch, reproducible through torch.manual_seed above.
190        order = torch.randperm(len(y))
191        total = 0.0
192        for i in range(0, len(y), batch_size):
193            batch = order[i:i + batch_size]
194            optimiser.zero_grad()
195            loss = loss_fn(model(x_cat[batch], x_num[batch]), y[batch])
196            loss.backward()
197            optimiser.step()
198            # Weight by batch size: the last batch is smaller, so total / len(y) is the mean loss per attempt.
199            total += loss.item() * len(batch)
200        # Dropout off for validation; the whole validation set goes through in one pass.
201        model.eval()
202        with torch.no_grad():
203            val_loss = loss_fn(model(v_cat, v_num), v_y).item()
204        scheduler.step(val_loss)
205        seconds = time.perf_counter() - start
206        # train_loss is averaged over the epoch with dropout on while the weights are still changing,
207        # so it can sit above val_loss, especially in early epochs. That is expected.
208        history.append({"epoch": epoch, "train_loss": total / len(y), "val_loss": val_loss, "seconds": seconds})
209        log(f"epoch {epoch:3d}  train {total / len(y):.4f}  val {val_loss:.4f}  ({seconds:.1f}s)")
210
211        # Only a fall of more than 1e-5 counts as an improvement, so negligible changes in the
212        # loss do not reset the patience counter.
213        if val_loss < best_loss - 1e-5:
214            # deepcopy: state_dict() returns references to the live tensors, which later optimiser
215            # steps would overwrite.
216            best_loss, best_state, stale = val_loss, copy.deepcopy(model.state_dict()), 0
217        else:
218            stale += 1
219            if stale >= patience:
220                log(f"validation loss stopped improving; keeping epoch {epoch - stale}")
221                break
222    # Restore the best epoch's weights, whether the loop ended early or ran all the epochs.
223    model.load_state_dict(best_state)
224    return OvertakePredictor(model, preprocessor), history

def expected_calibration_error(y, p, bins=10): 
281def expected_calibration_error(y, p, bins=10):
282    """Expected calibration error (ECE, as in Guo et al. 2017) over equal-width probability bins.
283
284    Predictions are grouped into ``bins`` bins of width ``1 / bins``. The
285    result is the sum over non-empty bins of (share of predictions in the bin)
286    x |mean predicted probability - observed overtake rate|.
287
288    Parameters
289    ----------
290    y : numpy.ndarray, shape (n,)
291        Observed 0/1 outcomes.
292    p : numpy.ndarray, shape (n,)
293        Predicted probabilities in [0, 1].
294    bins : int, optional
295        Number of equal-width bins (10).
296
297    Returns
298    -------
299    float
300        ECE as a probability; 0 means perfectly calibrated (x 100 for
301        percentage points).
302    """
303    # np.digitize gives 1..bins for p in [0, 1) and bins + 1 for p == 1; shift to 0-based and fold
304    # p == 1 into the last bin.
305    idx = np.clip(np.digitize(p, np.linspace(0, 1, bins + 1)) - 1, 0, bins - 1)
306    # (idx == b).mean() is the bin's share of all predictions, the ECE weight.
307    return float(sum(abs(p[idx == b].mean() - y[idx == b].mean()) * (idx == b).mean()
308                     for b in range(bins) if (idx == b).any()))
