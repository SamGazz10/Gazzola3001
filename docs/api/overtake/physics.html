overtake.physics

Straight-line dynamics of two 2026 F1 cars running nose to tail.

The closing stage of an overtaking attempt is an initial value problem. Each car has position x (m), speed v (m/s) and electrical energy used e (J), and obeys

dx/dt = v
m dv/dt = min(F_power, F_traction) - F_drag - F_rolling
de/dt = P_ers

where

  • F_power = eta (P_ice + P_ers) / v is the drive force the power unit can supply. P_ers is the MGU-K power, limited by the 2026 speed taper, by Boost / Overtake Mode, and by the energy left in the battery.
  • F_traction = mu * w_r * (m g + 1/2 rho ClA v^2) is the most the driven rear tyres can transmit. Below about 180 km/h this, not power, limits acceleration, which is how tyre grip enters the model.
  • F_drag = 1/2 rho CdA v^2. The following car's CdA is reduced by the slipstream, which decays with the distance between the cars.
  • F_rolling = c_rr (m g + 1/2 rho ClA v^2).

The two cars are coupled through the slipstream, so both are integrated together. Integration starts as both cars exit the corner before the run and stops when the defender reaches the braking point at the end of the run. The result is how far (in seconds) the attacker is still behind at that moment.

Two explicit fixed-step methods are provided: forward Euler (first order, used as a baseline) and classical Runge-Kutta (RK4, fourth order, used by the simulator). Both are verified against analytical solutions in tests/test_physics.py and overtake.experiments.

Parameter values are approximate public figures for 2026 cars or engineering estimates; they are collected in CarParameters so they can be changed.

108def mguk_power_limit(speed, overtake_mode, car=CarParameters()):
109    """Maximum MGU-K power allowed by the 2026 regulations at a given speed.
110
111    Parameters
112    ----------
113    speed : array_like
114        Car speed in m/s.
115    overtake_mode : array_like of bool
116        Whether Overtake Mode is active, which delays the taper.
117    car : CarParameters, optional
118        Supplies the 350 kW maximum.
119
120    Returns
121    -------
122    numpy.ndarray
123        Power limit in W, between 0 and ``car.mguk_power_w``.
124    """
125    kph = np.asarray(speed) * 3.6
126    start = np.where(overtake_mode, TAPER_OVERTAKE_MODE_KPH[0], TAPER_STANDARD_KPH[0])
127    end = TAPER_STANDARD_KPH[1]
128    return car.mguk_power_w * np.clip((end - kph) / (end - start), 0.0, 1.0)

168def acceleration(speed, energy_used, state, cda_m2, car=CarParameters()):
169    """Longitudinal acceleration and MGU-K power draw of one car.
170
171    Parameters
172    ----------
173    speed : numpy.ndarray
174        m/s. Values below 1 m/s are treated as 1 m/s to avoid dividing by zero.
175    energy_used : numpy.ndarray
176        Electrical energy used so far on this run, J.
177    state : CarState
178        The car's settings (tyre grip, deployment, energy available).
179    cda_m2 : numpy.ndarray
180        Drag area to use, i.e. ``state.cda_m2`` already reduced by any slipstream.
181    car : CarParameters, optional
182
183    Returns
184    -------
185    accel : numpy.ndarray
186        m/s^2.
187    ers_power : numpy.ndarray
188        MGU-K power actually drawn from the battery, W.
189    """
190    v = np.maximum(speed, 1.0)
191    remaining = np.clip((state.energy_j - energy_used) / car.energy_smoothing_j, 0.0, 1.0)
192    ers_available = state.deploy_share * mguk_power_limit(v, state.overtake_mode, car) * remaining
193
194    downforce = 0.5 * car.air_density * car.cla_m2 * v**2
195    normal_load = car.mass_kg * GRAVITY + downforce
196    f_power = car.drivetrain_efficiency * (car.ice_power_w + ers_available) / v
197    f_traction = state.mu * car.driven_axle_share * normal_load
198    f_drive = np.minimum(f_power, f_traction)
199
200    # When traction-limited the driver uses less power; the engine supplies
201    # first and the MGU-K only the remainder.
202    power_used = f_drive * v / car.drivetrain_efficiency
203    ers_power = np.clip(power_used - car.ice_power_w, 0.0, ers_available)
204
205    f_drag = 0.5 * car.air_density * cda_m2 * v**2
206    f_rolling = car.rolling_coeff * normal_load
207    return (f_drive - f_drag - f_rolling) / car.mass_kg, ers_power

210def slipstream_factor(separation_m, car=CarParameters()):
211    """Multiplier (<= 1) on the following car's drag area.
212
213    Parameters
214    ----------
215    separation_m : numpy.ndarray
216        Distance from the following car to the car ahead, m. Negative when the
217        follower has drawn alongside or ahead.
218    car : CarParameters, optional
219
220    Returns
221    -------
222    numpy.ndarray
223        ``1 - tow_max * exp(-separation / tow_length)`` behind the other car,
224        fading linearly to 1 over one car length as the follower draws
225        alongside.
226    """
227    sep = np.asarray(separation_m)
228    behind = np.exp(-np.maximum(sep, 0.0) / car.tow_length_m)
229    alongside = np.clip(1.0 + sep / car.car_length_m, 0.0, 1.0)
230    return 1.0 - car.tow_max * np.where(sep >= 0, behind, alongside)

233def two_car_rhs(y, attacker, defender, car=CarParameters()):
234    """Right-hand side of the coupled two-car system.
235
236    Parameters
237    ----------
238    y : numpy.ndarray, shape (6, n)
239        Rows are attacker position, speed, energy used, then the same for the
240        defender.
241    attacker, defender : CarState
242    car : CarParameters, optional
243
244    Returns
245    -------
246    numpy.ndarray, shape (6, n)
247        Time derivatives of ``y``.
248    """
249    xa, va, ea, xd, vd, ed = y
250    acc_a, ers_a = acceleration(va, ea, attacker, attacker.cda_m2 * slipstream_factor(xd - xa, car), car)
251    acc_d, ers_d = acceleration(vd, ed, defender, defender.cda_m2, car)
252    return np.stack([va, acc_a, ers_a, vd, acc_d, ers_d])

255def euler_step(f, y, dt):
256    """One forward Euler step of ``dy/dt = f(y)``. First order: error O(dt)."""
257    return y + dt * f(y)
258
259
260def rk4_step(f, y, dt):
261    """One classical Runge-Kutta step of ``dy/dt = f(y)``. Fourth order: error O(dt^4)."""
262    k1 = f(y)
263    k2 = f(y + 0.5 * dt * k1)
264    k3 = f(y + 0.5 * dt * k2)
265    k4 = f(y + dt * k3)
266    return y + dt / 6.0 * (k1 + 2 * k2 + 2 * k3 + k4)
267
268
269STEPPERS = {"euler": euler_step, "rk4": rk4_step}

272def integrate(f, y0, dt, n_steps, method="rk4"):
273    """Integrate an autonomous system ``dy/dt = f(y)`` with fixed steps.
274
275    Parameters
276    ----------
277    f : callable
278        Maps the state array to its time derivative (same shape).
279    y0 : numpy.ndarray
280        Initial state.
281    dt : float
282        Step size, s.
283    n_steps : int
284        Number of steps.
285    method : {"rk4", "euler"}
286
287    Returns
288    -------
289    numpy.ndarray
290        State after ``n_steps * dt`` seconds.
291    """
292    step = STEPPERS[method]
293    y = np.array(y0, dtype=float)
294    for _ in range(n_steps):
295        y = step(f, y, dt)
296    return y

299def _hermite(p0, m0, p1, m1, s, dt):
300    """Cubic Hermite interpolation on [0, dt] at fraction ``s`` in [0, 1]."""
301    h00 = 2 * s**3 - 3 * s**2 + 1
302    h10 = s**3 - 2 * s**2 + s
303    h01 = -2 * s**3 + 3 * s**2
304    h11 = s**3 - s**2
305    return h00 * p0 + h10 * dt * m0 + h01 * p1 + h11 * dt * m1
306

308def _crossing_fraction(x0, v0, x1, v1, target, dt, iterations=4):
309    """Fraction of the step at which the Hermite cubic through (x0, v0), (x1, v1) reaches ``target``.
310
311    Starts from linear interpolation and refines with Newton's method. Hermite
312    interpolation is fourth-order accurate, matching RK4.
313    """
314    s = np.clip((target - x0) / np.maximum(x1 - x0, 1e-12), 0.0, 1.0)
315    for _ in range(iterations):
316        value = _hermite(x0, v0, x1, v1, s, dt) - target
317        slope = (6 * s**2 - 6 * s) * x0 + (3 * s**2 - 4 * s + 1) * dt * v0 \
318            + (-6 * s**2 + 6 * s) * x1 + (3 * s**2 - 2 * s) * dt * v1
319        s = np.clip(s - value / np.where(np.abs(slope) > 1e-12, slope, 1e-12), 0.0, 1.0)
320    return s

351def run_to_braking_point(run_length_m, gap_s, attacker_speed0, defender_speed0, attacker, defender,
352                         car=CarParameters(), dt=0.05, method="rk4", max_time_s=60.0):
353    """Integrate both cars from the corner exit until the defender reaches the braking point.
354
355    All scenarios are integrated together as NumPy arrays. Scenarios drop out
356    of the active set as soon as their defender crosses the braking point; the
357    exact crossing time within the last step is found by Hermite interpolation.
358
359    Parameters
360    ----------
361    run_length_m : array_like
362        Distance from the corner exit to the braking point, m. Must be > 0.
363    gap_s : array_like
364        Time gap at the corner exit, s. The attacker starts ``gap_s *
365        defender_speed0`` metres behind.
366    attacker_speed0, defender_speed0 : array_like
367        Corner-exit speeds, m/s.
368    attacker, defender : CarState
369    car : CarParameters, optional
370    dt : float, optional
371        Time step, s. 0.05 s keeps the deficit error below 1 ms (see
372        ``overtake.experiments.timestep``).
373    method : {"rk4", "euler"}, optional
374    max_time_s : float, optional
375        Safety limit; a RuntimeError is raised if a car has not reached the
376        braking point by then (e.g. a non-physical input left it stationary).
377
378    Returns
379    -------
380    RunResult
381
382    Raises
383    ------
384    RuntimeError
385        If integration exceeds ``max_time_s``.
386    """
387    length = np.asarray(run_length_m, dtype=float)
388    n = length.size
389    y = np.stack([
390        -np.asarray(gap_s, dtype=float) * defender_speed0,
391        np.asarray(attacker_speed0, dtype=float),
392        np.zeros(n),
393        np.zeros(n),
394        np.asarray(defender_speed0, dtype=float),
395        np.zeros(n),
396    ])
397    final = np.full((6, n), np.nan)
398    finish_time = np.full(n, np.nan)
399    active = np.arange(n)
400    att, dfd, target = attacker, defender, length
401    step = STEPPERS[method]
402    t, steps = 0.0, 0
403
404    def f(state):
405        return two_car_rhs(state, att, dfd, car)
406
407    while active.size:
408        if t > max_time_s:
409            raise RuntimeError(f"{active.size} scenario(s) did not reach the braking point in {max_time_s} s")
410        y_new = step(f, y, dt)
411        crossed = y_new[3] >= target
412        if crossed.any():
413            att_x, dfd_x = att.take(crossed), dfd.take(crossed)
414            d_old = two_car_rhs(y[:, crossed], att_x, dfd_x, car)
415            d_new = two_car_rhs(y_new[:, crossed], att_x, dfd_x, car)
416            s = _crossing_fraction(y[3, crossed], y[4, crossed], y_new[3, crossed], y_new[4, crossed],
417                                   target[crossed], dt)
418            idx = active[crossed]
419            for row in range(6):
420                final[row, idx] = _hermite(y[row, crossed], d_old[row], y_new[row, crossed], d_new[row], s, dt)
421            finish_time[idx] = t + s * dt
422            keep = ~crossed
423            active, y_new, target = active[keep], y_new[:, keep], target[keep]
424            att, dfd = att.take(keep), dfd.take(keep)
425        y = y_new
426        t += dt
427        steps += 1
428
429    xa, va, ea, xd, vd, ed = final
430    return RunResult(
431        deficit_s=(xd - xa) / np.maximum(va, 1.0),
432        attacker_speed=va,
433        defender_speed=vd,
434        attacker_energy_j=ea,
435        defender_energy_j=ed,
436        time_s=finish_time,
437        steps=steps,
438    )

171

173    ----------
174    speed : numpy.ndarray
175        m/s. Values below 1 m/s are treated as 1 m/s to avoid dividing by zero.
176    energy_used : numpy.ndarray
177        Electrical energy used so far on this run, J.
178    state : CarState
179        The car's settings (tyre grip, deployment, energy available).

190    """

192    remaining = np.clip((state.energy_j - energy_used) / car.energy_smoothing_j, 0.0, 1.0)

200

207    f_rolling = car.rolling_coeff * normal_load
