overtake.realdata

Real 2026 race data from the OpenF1 API, for comparison with the simulator.

python -m overtake.realdata download      # fetch and cache (about 4 minutes, once)
python -m overtake.experiments real       # download if needed, analyse, write
                                          # reports/results/real_data.json and four figures

From Python::

from overtake import realdata
realdata.download()
result = realdata.analyse()     # dict described in `analyse`

OpenF1 (https://openf1.org) is a free, unofficial API of Formula 1 timing data. No public source records battery charge or Boost / Overtake Mode use (the old DRS channel is empty in 2026), so the real data can test the simulator only indirectly: speeds, overtakes and gaps.

Responses are cached as JSON under data/real/openf1/ (not in git), so the download runs once and every later analysis is offline and repeatable. OpenF1's free tier allows about 30 requests a minute, so requests are spaced 2.2 s apart.

The analysis functions take plain OpenF1 rows (lists of dicts), so they can be used and tested without the network.

 58def fetch(endpoint, **params):
 59    """Return an OpenF1 response, from the cache if present, otherwise from the API.
 60
 61    Every response, an empty one included, is saved under `CACHE` and never
 62    refreshed: a race fetched before OpenF1 had its data stays empty until its
 63    file is deleted. API calls are spaced at least `REQUEST_SPACING_S` apart,
 64    and a rate-limited call (HTTP 429) is retried after 15, 30 and 45 s.
 65
 66    Parameters
 67    ----------
 68    endpoint : str
 69        OpenF1 endpoint name, e.g. ``"laps"``.
 70    **params
 71        Query parameters, e.g. ``session_key=11361``. They also name the cache file.
 72
 73    Returns
 74    -------
 75    list of dict
 76        One dict per OpenF1 record; ``[]`` if OpenF1 answers 404 ("No results found").
 77
 78    Raises
 79    ------
 80    urllib.error.HTTPError
 81        For an HTTP error other than 404, or a fourth 429 in a row.
 82    urllib.error.URLError
 83        If the data is not cached and the API cannot be reached.
 84    TimeoutError
 85        If the response stalls for 120 s (the socket timeout) after the request is sent.
 86
 87    Examples
 88    --------
 89    >>> laps = fetch("laps", session_key=11361)   # doctest: +SKIP
 90    """
 91    global _last_request
 92    # Cache file named by the endpoint and the sorted parameters, e.g. laps_session_key-11361.json.
 93    name = endpoint + "".join(f"_{k}-{v}" for k, v in sorted(params.items())) + ".json"
 94    path = CACHE / name
 95    if path.exists():
 96        return json.loads(path.read_text())
 97    # Spacing runs from the end of the previous API call to the start of this one.
 98    wait = REQUEST_SPACING_S - (time.monotonic() - _last_request)
 99    if wait > 0:
100        time.sleep(wait)
101    url = f"{API}/{endpoint}?{urllib.parse.urlencode(params)}"
102    for attempt in range(4):  # up to 4 attempts; only a 429 is retried, after 15, 30, then 45 s
103        try:
104            with urllib.request.urlopen(url, timeout=120) as response:  # socket timeout, s (estimate)
105                data = json.loads(response.read())
106            break
107        except urllib.error.HTTPError as error:
108            if error.code == 404:  # OpenF1 answers 404 "No results found" when there is no data
109                data = []
110                break
111            if error.code != 429 or attempt == 3:  # 429 = rate limited: wait and retry
112                raise
113            time.sleep(15 * (attempt + 1))
114    _last_request = time.monotonic()
115    CACHE.mkdir(parents=True, exist_ok=True)
116    path.write_text(json.dumps(data))
117    return data

120def completed_races(year=2026, before=RACES_BEFORE):
121    """Grand Prix races (not sprints) of ``year`` dated before ``before`` (YYYY-MM-DD).
122
123    Some may have no data in OpenF1; `download` and `analyse` skip those.
124
125    Parameters
126    ----------
127    year : int, optional
128        Season.
129    before : str, optional
130        Cut-off date "YYYY-MM-DD", exclusive, compared with the date part of the
131        race's ``date_start`` (UTC). Fixed by default (`RACES_BEFORE`) so later
132        races do not change the results.
133
134    Returns
135    -------
136    list of dict
137        OpenF1 ``sessions`` records (``session_key``, ``circuit_short_name``,
138        ``date_start``, ...), in the order OpenF1 returns them.
139
140    Raises
141    ------
142    urllib.error.URLError
143        If the session list is not cached and OpenF1 cannot be reached (see `fetch`).
144    """
145    sessions = fetch("sessions", year=year, session_type="Race")
146    # Session type "Race" also covers sprints; session_name tells them apart. ISO dates compare as strings.
147    return [s for s in sessions if s["session_name"] == "Race" and s["date_start"][:10] < before]

150def download(log=print):
151    """Fetch and cache everything the comparison needs.
152
153    For every completed race (`completed_races`) with lap data, each of the
154    `RACE_ENDPOINTS`; then the telemetry (``car_data``) of car
155    ``TELEMETRY["driver_number"]`` at the ``TELEMETRY["session"]`` race.
156    Cached responses are not fetched again, so a second run is offline. This
157    is what ``python -m overtake.realdata download`` runs.
158
159    Parameters
160    ----------
161    log : callable, optional
162        Receives the progress lines: the race count, one line per race and one
163        for the telemetry (default `print`).
164
165    Returns
166    -------
167    list of dict
168        OpenF1 session records of every completed race, including those
169        skipped for having no data.
170
171    Raises
172    ------
173    urllib.error.URLError
174        If something is not cached and OpenF1 cannot be reached (see `fetch`
175        for the other network errors).
176    StopIteration
177        If the ``TELEMETRY["session"]`` race is not among the completed races.
178
179    Examples
180    --------
181    >>> races = download(log=lambda line: None)   # doctest: +SKIP
182    """
183    races = completed_races()
184    log(f"{len(races)} completed races")
185    for race in races:
186        if not fetch("laps", session_key=race["session_key"]):
187            log(f"  {race['circuit_short_name']:18s} no data in OpenF1, skipped")
188            continue
189        counts = []
190        for endpoint in RACE_ENDPOINTS:
191            counts.append(f"{endpoint} {len(fetch(endpoint, session_key=race['session_key']))}")
192        log(f"  {race['circuit_short_name']:18s} " + ", ".join(counts))
193    monza = next(r for r in races if r["circuit_short_name"] == TELEMETRY["session"])
194    rows = fetch("car_data", session_key=monza["session_key"], driver_number=TELEMETRY["driver_number"])
195    log(f"  telemetry: car {TELEMETRY['driver_number']} at Monza, {len(rows):,} samples")
196    return races

221def _times(values):
222    """Parse OpenF1 timestamps to timezone-naive UTC (so every comparison uses one convention).
223
224    ``format="ISO8601"`` accepts the mix of ISO 8601 variants OpenF1 returns;
225    comparing timezone-aware with naive times would raise. Returns a
226    `pandas.Series` of naive UTC times in input order.
227    """
228    return pd.to_datetime(pd.Series(values), utc=True, format="ISO8601").dt.tz_localize(None)

231def lap_index(laps):
232    """Start time of every lap of every driver, for looking up which lap a moment falls in.
233
234    Parameters
235    ----------
236    laps : list of dict
237        OpenF1 ``laps`` rows.
238
239    Returns
240    -------
241    dict of int -> pandas.DataFrame
242        Per driver: ``lap_number``, ``start`` (naive UTC), ``pit_out`` (bool), sorted
243        by lap. Lap 1 has no recorded start (standing start) and is left out, and
244        a driver with no recorded lap start has no entry.
245    """
246    df = pd.DataFrame(laps)
247    df = df[df["date_start"].notna()].copy()
248    df["start"] = _times(df["date_start"]).values
249    out = {}
250    for driver, rows in df.groupby("driver_number"):
251        out[int(driver)] = rows.sort_values("lap_number")[["lap_number", "start", "is_pit_out_lap"]].rename(
252            columns={"is_pit_out_lap": "pit_out"}).reset_index(drop=True)
253    return out

256def lap_at(index, driver, when):
257    """Lap a driver was on at a given moment.
258
259    Parameters
260    ----------
261    index : dict of int -> pandas.DataFrame
262        Output of `lap_index`.
263    driver : int
264        Driver number.
265    when : pandas.Timestamp or numpy.datetime64
266        Moment to look up, timezone-naive UTC (as from `_times`).
267
268    Returns
269    -------
270    int or None
271        Lap number; 1 if ``when`` is before the driver's first recorded lap
272        start (normally lap 2's, as lap 1 has none); None if the driver has no
273        lap data.
274    """
275    rows = index.get(int(driver))
276    if rows is None or rows.empty:
277        return None
278    # Index of the last lap that started at or before `when`; -1 means none has, so still lap 1.
279    i = rows["start"].searchsorted(when, side="right") - 1
280    return 1 if i < 0 else int(rows["lap_number"].iloc[i])

284NEUTRALISING = {"OVERTAKE DISABLED": "overtake mode", "SAFETY CAR DEPLOYED": "safety car",
285                "VSC DEPLOYED": "safety car", "RED FLAG - RACE SUSPENDED": "red flag"}

288def neutralised_periods(race_control):
289    """Time intervals without normal racing with Overtake Mode available, from race-control messages.
290
291    A period starts with OVERTAKE DISABLED, SAFETY CAR DEPLOYED, VSC DEPLOYED
292    or RED FLAG and lasts until every such cause has ended: OVERTAKE ENABLED
293    ends all of them; TRACK CLEAR also ends a (virtual) safety car, but not a
294    red flag, after which the race restarts from the grid. Both kinds of
295    message are needed because race control does not announce every safety
296    car with OVERTAKE DISABLED.
297
298    Parameters
299    ----------
300    race_control : list of dict
301        OpenF1 ``race_control`` rows for one race.
302
303    Returns
304    -------
305    list of (pandas.Timestamp, pandas.Timestamp)
306        Start and end (naive UTC), in time order; the end is
307        ``pandas.Timestamp.max`` if the race finished neutralised.
308    """
309    rows = sorted(race_control, key=lambda m: m["date"])
310    times = _times([m["date"] for m in rows])
311    # `active` holds the kinds of neutralisation in force; a period lasts while it is non-empty.
312    active, periods, start = set(), [], None
313    for m, when in zip(rows, times):
314        message = m.get("message") or ""
315        if message in NEUTRALISING:
316            active.add(NEUTRALISING[message])
317        elif message == "OVERTAKE ENABLED":
318            active.clear()
319        elif message == "TRACK CLEAR":
320            active.discard("safety car")
321        if active and start is None:
322            start = when
323        elif not active and start is not None:
324            periods.append((start, when))
325            start = None
326    if start is not None:
327        periods.append((start, pd.Timestamp.max))
328    return periods

331def _pit_laps(pits):
332    """Map driver number -> set of laps on which OpenF1 records a pit stop (rows with no lap are skipped)."""
333    out = {}
334    for p in pits:
335        if p.get("lap_number") is not None:
336            out.setdefault(int(p["driver_number"]), set()).add(int(p["lap_number"]))
337    return out

340def classify_overtakes(overtakes, laps, pits, race_control=()):
341    """Label every position change with why it happened.
342
343    OpenF1's overtakes are position changes between two cars. Each gets the
344    first reason that applies, judged on the overtaking car's lap at the moment
345    of the change (`lap_at`):
346
347    * ``"start"``: lap 1, where positions shuffle from a standing start;
348    * ``"neutralised"``: under a safety car, virtual safety car or red flag, or
349      while race control had disabled Overtake Mode (`neutralised_periods`);
350    * ``"pit stop"``: either car pitted on that lap or the lap before, or is
351      on a pit-out lap (one car stopping for tyres is not an overtake);
352    * ``"on track"``: everything else.
353
354    Not identifiable from the data, so left as on-track passes: passes on cars
355    slowing with a problem. A change whose lap is unknown (the overtaking car
356    has no lap data) is ``"start"`` only in a race where no change's lap is
357    known; otherwise its lap is NaN, which passes neither lap test, so it ends
358    up ``"neutralised"`` or ``"on track"``.
359
360    Parameters
361    ----------
362    overtakes, laps, pits : list of dict
363        OpenF1 ``overtakes``, ``laps`` and ``pit`` rows for one race.
364    race_control : sequence of dict, optional
365        OpenF1 ``race_control`` rows; empty (the default) means no neutralised periods.
366
367    Returns
368    -------
369    pandas.DataFrame
370        The overtakes with ``time`` (naive UTC), ``lap`` (the overtaking car's
371        lap) and ``reason`` (one of the four labels) added. With no overtakes,
372        an empty table that still has those three columns.
373    """
374    df = pd.DataFrame(overtakes)
375    # Keep the output columns for a race with no overtakes, so callers can still filter on reason.
376    if df.empty:
377        return df.assign(time=pd.Series(dtype="datetime64[ns]"), lap=pd.Series(dtype=int),
378                         reason=pd.Series(dtype=str))
379    index, pit_laps = lap_index(laps), _pit_laps(pits)
380    periods = neutralised_periods(race_control)
381    df["time"] = _times(df["date"]).values
382    # The overtaking car's lap at the moment of the change; the pit checks below use it for both cars.
383    df["lap"] = [lap_at(index, d, t) for d, t in zip(df["overtaking_driver_number"], df["time"])]
384
385    def pit_related(driver, lap):
386        """True if ``driver`` pitted on ``lap`` or ``lap - 1``, or ``lap`` is their pit-out lap."""
387        rows = index.get(int(driver))
388        out_lap = rows is not None and bool(rows.loc[rows["lap_number"] == lap, "pit_out"].any())
389        return out_lap or bool(pit_laps.get(int(driver), set()) & {lap, lap - 1})
390
391    def reason(a, b, lap, when):
392        """First label that applies to a change by car ``a`` on car ``b`` on ``lap`` at ``when``."""
393        # None: unknown lap. Mixed with known laps the column is float and an unknown lap is NaN,
394        # which neither test catches (see `classify_overtakes`).
395        if lap is None or lap <= 1:
396            return "start"
397        if any(lo <= when < hi for lo, hi in periods):
398            return "neutralised"
399        if pit_related(a, lap) or pit_related(b, lap):
400            return "pit stop"
401        return "on track"
402
403    df["reason"] = [reason(a, b, lap, t) for a, b, lap, t in
404                    zip(df["overtaking_driver_number"], df["overtaken_driver_number"], df["lap"], df["time"])]
405    return df

409    """Only the position changes that look like real on-track passes (see `classify_overtakes`).

428def wilson_interval(successes, n, z=1.96):
429    """Wilson score interval for a binomial proportion (Wilson, 1927).
430
431    Unlike the normal (Wald) interval it behaves well for small ``n`` and for
432    rates near 0 or 1: it stays inside [0, 1] (up to rounding) and is not zero
433    width when there are no successes.
434
435    Parameters
436    ----------
437    successes : int
438        Number of successes (here passes), 0 <= successes <= n.
439    n : int
440        Number of trials (here driver-laps).
441    z : float, optional
442        Standard-normal quantile; the default 1.96 gives a 95 % interval.
443
444    Returns
445    -------
446    (low, high) : tuple of float
447        Bounds as proportions; ``(nan, nan)`` if ``n == 0``.
448
449    Examples
450    --------
451    >>> [round(float(b), 4) for b in wilson_interval(5, 10)]
452    [0.2366, 0.7634]
453    """
454    if n == 0:
455        return (np.nan, np.nan)
456    p = successes / n
457    # Roots in p of (p_hat - p)^2 = z^2 p (1 - p) / n; the centre moves from p_hat towards 1/2.
458    centre = (p + z * z / (2 * n)) / (1 + z * z / n)
459    half = z * np.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / (1 + z * z / n)
460    return (centre - half, centre + half)

463def laps_by_gap(laps, intervals, pits, passes, race_control=()):
464    """One row per driver-lap: gap to the car ahead at the start of the lap, and whether the driver passed.
465
466    The gap is the ``interval`` sample nearest the lap's start (within 10 s);
467    the lap counts as a pass if the driver made an on-track overtake before
468    their next lap began. Lap 1, pit in/out laps, laps that overlap a
469    neutralised period (`neutralised_periods`), the race leader and lapped
470    gaps ("+1 LAP") are left out. So is each driver's last recorded lap,
471    whose end (the next lap's start) is unknown. A lap on which the car ahead
472    pits stays in as a non-pass: only the driver's own pit laps are dropped.
473
474    Parameters
475    ----------
476    laps, intervals, pits : list of dict
477        OpenF1 ``laps``, ``intervals`` and ``pit`` rows for one race.
478    passes : pandas.DataFrame
479        On-track passes, e.g. from `on_track_overtakes`; only
480        ``overtaking_driver_number`` and ``time`` (naive UTC) are used.
481    race_control : sequence of dict, optional
482        OpenF1 ``race_control`` rows; empty (the default) means no neutralised periods.
483
484    Returns
485    -------
486    pandas.DataFrame
487        Columns ``driver`` (int), ``lap`` (int), ``gap_s`` (gap to the car
488        ahead, s) and ``passed`` (bool).
489
490    Raises
491    ------
492    KeyError
493        If ``intervals`` is empty (no ``interval`` column).
494    """
495    index = lap_index(laps)
496    iv = pd.DataFrame(intervals)
497    # The leader's interval is None and a lapped car's "+1 LAP": both become NaN and are dropped, as are gaps <= 0.
498    iv["gap"] = pd.to_numeric(iv["interval"], errors="coerce")
499    iv = iv[iv["gap"].notna() & (iv["gap"] > 0)].copy()
500    iv["time"] = _times(iv["date"]).values
501    pit_laps, periods = _pit_laps(pits), neutralised_periods(race_control)
502    pass_times = {}
503    for d, t in zip(passes.get("overtaking_driver_number", []), passes.get("time", [])):
504        pass_times.setdefault(int(d), []).append(t)
505
506    rows = []
507    for driver, lap_rows in index.items():
508        samples = iv[iv["driver_number"] == driver].sort_values("time")
509        if samples.empty:
510            continue
511        times = samples["time"].to_numpy()
512        mine = np.array(sorted(pass_times.get(driver, [])), dtype="datetime64[ns]")
513        # Lap i runs from its start to lap i + 1's start, so the last recorded lap has no end and is skipped.
514        for i in range(len(lap_rows) - 1):
515            lap, start, end = int(lap_rows["lap_number"][i]), lap_rows["start"][i], lap_rows["start"][i + 1]
516            if lap <= 1 or lap_rows["pit_out"][i] or lap in pit_laps.get(driver, set()):
517                continue
518            if any(lo < end and start < hi for lo, hi in periods):  # overlaps a neutralised period at all
519                continue
520            # Nearest interval sample to the lap start, on either side (samples come about every 4 s).
521            j = np.searchsorted(times, start.to_datetime64())
522            candidates = [k for k in (j - 1, j) if 0 <= k < len(times)]
523            k = min(candidates, key=lambda k: abs(times[k] - start.to_datetime64()))
524            if abs(times[k] - start.to_datetime64()) > np.timedelta64(10, "s"):  # 10 s: estimate
525                continue
526            # A pass counts for this lap if it falls in [start, end).
527            passed = bool(((mine >= start.to_datetime64()) & (mine < end.to_datetime64())).any())
528            rows.append((driver, lap, float(samples["gap"].iloc[k]), passed))
529    return pd.DataFrame(rows, columns=["driver", "lap", "gap_s", "passed"])

532def rate_by_gap(gap_s, passed, bins=GAP_BINS):
533    """Pass rate (with 95 % Wilson interval) in each gap bin.
534
535    Parameters
536    ----------
537    gap_s : array_like of float
538        Gap to the car ahead at the start of each driver-lap, s.
539    passed : array_like of bool
540        Whether the driver made an on-track pass on that lap.
541    bins : sequence of float, optional
542        Increasing bin edges, s. Bins are half-open, [low, high); gaps outside
543        [bins[0], bins[-1]) are not counted.
544
545    Returns
546    -------
547    list of dict
548        One per bin: ``bin`` (label, e.g. "0.25-0.5"), ``low``/``high`` (edges, s),
549        ``n`` (driver-laps), ``passes``, ``rate`` (passes / n) and ``ci`` ([low, high]
550        as proportions, `wilson_interval`). For an empty bin ``rate`` is None and
551        ``ci`` is ``[None, None]``, which become JSON null (NaN is not valid JSON).
552    """
553    gap_s, passed = np.asarray(gap_s, dtype=float), np.asarray(passed, dtype=bool)
554    out = []
555    for lo, hi in zip(bins[:-1], bins[1:]):
556        mask = (gap_s >= lo) & (gap_s < hi)
557        n, k = int(mask.sum()), int(passed[mask].sum())
558        out.append({"bin": f"{lo:g}-{hi:g}", "low": lo, "high": hi, "n": n, "passes": k,
559                    "rate": k / n if n else None, "ci": list(wilson_interval(k, n)) if n else [None, None]})
560    return out

563def full_throttle_runs(car_data, min_seconds=6.0, min_gain_kph=80):
564    """Stretches of telemetry where the car accelerates flat out (straights).
565
566    A run is a sequence of samples with throttle >= 99 % and no brake, lasting
567    at least ``min_seconds`` and gaining at least ``min_gain_kph``. Distance
568    is the trapezoidal integral of speed over time.
569
570    Parameters
571    ----------
572    car_data : list of dict
573        OpenF1 ``car_data`` rows for one car: ``date`` (ISO 8601), ``speed``
574        (km/h), ``throttle`` (%), ``brake`` (0 or 100). Any order; sorted by
575        time here.
576    min_seconds : float, optional
577        Shortest run kept, s, from its first sample to its last.
578    min_gain_kph : float, optional
579        Smallest rise from the run's first speed to its peak, km/h.
580
581    Returns
582    -------
583    list of pandas.DataFrame
584        Per run, in time order: ``t`` (s from run start), ``x`` (m from run
585        start), ``kph``.
586
587    Raises
588    ------
589    KeyError
590        If ``car_data`` is empty (no ``date`` column).
591    """
592    df = pd.DataFrame(car_data)
593    df["time"] = _times(df["date"]).values
594    df = df.sort_values("time").reset_index(drop=True)
595    flat = (df["throttle"] >= 99) & (df["brake"] == 0)  # 99 % rather than exactly 100 % (estimate)
596    runs, start = [], None
597    # A trailing False closes a run that lasts to the end of the data.
598    for i, on in enumerate(list(flat) + [False]):
599        if on and start is None:
600            start = i
601        elif not on and start is not None:
602            seg = df.iloc[start:i]
603            t = (seg["time"] - seg["time"].iloc[0]).dt.total_seconds().to_numpy()
604            v = seg["speed"].to_numpy(dtype=float) / 3.6  # km/h -> m/s for the distance integral
605            if t[-1] >= min_seconds and (v.max() - v[0]) * 3.6 >= min_gain_kph:
606                # Cumulative trapezoidal rule: distance from the run start, m.
607                x = np.concatenate([[0.0], np.cumsum(0.5 * (v[1:] + v[:-1]) * np.diff(t))])
608                runs.append(pd.DataFrame({"t": t, "x": x, "kph": v * 3.6}))
609            start = None
610    return runs

613def simulate_run(v0_kph, duration_s, deploy_share, overtake_mode=False, battery=1.0, dt=0.05):
614    """Speed of one car accelerating from ``v0_kph`` for ``duration_s``, from the simulator's physics.
615
616    Integrates the one-car ODE with the simulator's force model
617    (`overtake.physics.acceleration`) and fixed-step RK4
618    (`overtake.physics.rk4_step`): new soft tyre (``mu_reference``), dry, no
619    slipstream, no braking.
620
621    Parameters
622    ----------
623    v0_kph : float
624        Starting speed, km/h.
625    duration_s : float
626        Length of the run, s; rounded to a whole number of steps.
627    deploy_share : float
628        Share of the MGU-K limit used: 1 with Boost,
629        `overtake.simulator.STANDARD_MAP_SHARE` (0.55) on the standard map, 0
630        with no electrical power.
631    overtake_mode : bool, optional
632        Overtake Mode: the MGU-K taper starts at 337 km/h instead of 290 km/h,
633        and 0.5 MJ of extra energy (`overtake.physics.OVERTAKE_MODE_EXTRA_J`).
634    battery : float, optional
635        Starting charge as a fraction (0-1) of the usable 4 MJ
636        (`overtake.physics.BATTERY_USABLE_J`), not a percentage as in the
637        simulator's scenarios.
638    dt : float, optional
639        RK4 step, s; the default equals the simulator's ``TIME_STEP_S``.
640
641    Returns
642    -------
643    pandas.DataFrame
644        One row per step from t = 0 to the rounded duration: ``t`` (s), ``x``
645        (distance, m), ``kph`` (speed, km/h).
646    """
647    car = physics.CarParameters()
648    # One scenario: `physics` works on arrays with one entry per scenario.
649    state = physics.CarState(mu=np.array([car.mu_reference]), cda_m2=np.array([car.cda_m2]),
650                             deploy_share=np.array([float(deploy_share)]),
651                             energy_j=np.array([physics.BATTERY_USABLE_J * battery
652                                                + physics.OVERTAKE_MODE_EXTRA_J * overtake_mode]),
653                             overtake_mode=np.array([overtake_mode]))
654
655    def f(y):
656        """Right-hand side for y = [x (m), v (m/s), energy used (J)]: dy/dt = [v, a, MGU-K power]."""
657        # One-element slices in, first elements out, as `physics.acceleration` works on arrays.
658        accel, ers = physics.acceleration(y[1:2], y[2:3], state, state.cda_m2, car)
659        return np.array([y[1], accel[0], ers[0]])
660
661    y, rows = np.array([0.0, v0_kph / 3.6, 0.0]), []  # start at x = 0, km/h -> m/s, no energy used
662    # Record the state, then step; the step taken after the last row is not used.
663    for i in range(int(round(duration_s / dt)) + 1):
664        rows.append((i * dt, y[0], y[1] * 3.6))
665        y = physics.rk4_step(f, y, dt)
666    return pd.DataFrame(rows, columns=["t", "x", "kph"])

698

431
432    Unlike the normal (Wald) interval it behaves well for small ``n`` and for
433    rates near 0 or 1: it stays inside [0, 1] (up to rounding) and is not zero
434    width when there are no successes.
435
436    Parameters
437    ----------
438    successes : int

455    if n == 0:

460    half = z * np.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / (1 + z * z / n)

580        Smallest rise from the run's first speed to its peak, km/h.
581

584    list of pandas.DataFrame
585        Per run, in time order: ``t`` (s from run start), ``x`` (m from run
586        start), ``kph``.

589    ------
590    KeyError
591        If ``car_data`` is empty (no ``date`` column).

595    df = df.sort_values("time").reset_index(drop=True)
596    flat = (df["throttle"] >= 99) & (df["brake"] == 0)  # 99 % rather than exactly 100 % (estimate)
597    runs, start = [], None

599    for i, on in enumerate(list(flat) + [False]):
600        if on and start is None:
601            start = i
602        elif not on and start is not None:
603            seg = df.iloc[start:i]
604            t = (seg["time"] - seg["time"].iloc[0]).dt.total_seconds().to_numpy()
605            v = seg["speed"].to_numpy(dtype=float) / 3.6  # km/h -> m/s for the distance integral
606            if t[-1] >= min_seconds and (v.max() - v[0]) * 3.6 >= min_gain_kph:
607                # Cumulative trapezoidal rule: distance from the run start, m.
608                x = np.concatenate([[0.0], np.cumsum(0.5 * (v[1:] + v[:-1]) * np.diff(t))])
609                runs.append(pd.DataFrame({"t": t, "x": x, "kph": v * 3.6}))
610            start = None
611    return runs

618    (`overtake.physics.acceleration`) and fixed-step RK4

630        `overtake.simulator.STANDARD_MAP_SHARE` (0.55) on the standard map, 0
631        with no electrical power.

634        and 0.5 MJ of extra energy (`overtake.physics.OVERTAKE_MODE_EXTRA_J`).

641

643    -------
644    pandas.DataFrame

646        (distance, m), ``kph`` (speed, km/h).
647    """
648    car = physics.CarParameters()
649    # One scenario: `physics` works on arrays with one entry per scenario.
650    state = physics.CarState(mu=np.array([car.mu_reference]), cda_m2=np.array([car.cda_m2]),
651                             deploy_share=np.array([float(deploy_share)]),
652                             energy_j=np.array([physics.BATTERY_USABLE_J * battery
653                                                + physics.OVERTAKE_MODE_EXTRA_J * overtake_mode]),
654                             overtake_mode=np.array([overtake_mode]))
655
656    def f(y):
657        """Right-hand side for y = [x (m), v (m/s), energy used (J)]: dy/dt = [v, a, MGU-K power]."""
658        # One-element slices in, first elements out, as `physics.acceleration` works on arrays.
659        accel, ers = physics.acceleration(y[1:2], y[2:3], state, state.cda_m2, car)
660        return np.array([y[1], accel[0], ers[0]])
661

665        rows.append((i * dt, y[0], y[1] * 3.6))
666        y = physics.rk4_step(f, y, dt)
