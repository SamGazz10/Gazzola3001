overtake.simulator

Simulator of one overtaking attempt under the 2026 rules.

No public dataset of 2026 overtakes records battery charge and Boost / Overtake Mode use, so the network is trained on attempts generated here. An attempt has two stages.

1. Closing (deterministic physics). overtake.physics integrates both cars from the corner exit to the braking point and returns the gap the attacker still has to close, D (s). Tyres set grip and corner-exit speed, the battery and Boost / Overtake Mode set the electrical power, the slipstream cuts the attacker's drag, and car performance differences shift exit speed and drag. Poor-weather caution and the defender's positioning add to D.

2. Execution (random). Driver execution varies from attempt to attempt, modelled as Gaussian noise eps ~ N(0, sigma) on the deficit. The attacker can lunge if D - eps is within LUNGE_RANGE_S; the margin is then u = eps - (D - LUNGE_RANGE_S). A lunge sticks with probability logistic(z0 + 5 min(u, 0.5)), where z0 collects driver ratings, braking grip, corner type, weather and circuit.

Because the randomness is a single Gaussian variable, the exact probability of an overtake is a one-dimensional integral,

P = integral_0^inf  phi_sigma(u + D - LUNGE_RANGE_S) logistic(z0 + 5 min(u, 0.5)) du,

which probability evaluates by Gauss-Legendre quadrature on [0, 0.5] and in closed form beyond. This gives a ground truth to validate the network against. simulate instead draws the random variables, producing the 0/1 outcomes the network is trained on, exactly as real race data would look.

Constants marked "estimate" are engineering judgements chosen to give plausible magnitudes, not values measured from F1 data.

 86def tyre_grip(compound, age, condition, track_temp):
 87    """Grip of a tyre relative to a new soft on a dry track.
 88
 89    Parameters
 90    ----------
 91    compound, condition : array_like of str
 92        Tyre compound and track condition per scenario.
 93    age : array_like
 94        Tyre age in laps.
 95    track_temp : array_like
 96        Track temperature, deg C. Hot tracks wear tyres faster; hard tyres
 97        lose grip on a cold track.
 98
 99    Returns
100    -------
101    numpy.ndarray
102        Relative grip, about 0.5-1.0.
103    """
104    compound, condition = np.asarray(compound), np.asarray(condition)
105    age, track_temp = np.asarray(age, dtype=float), np.asarray(track_temp, dtype=float)
106    base = pd.Series(list(zip(condition, compound))).map(
107        {(c, t): GRIP[c][t] for c in CONDITIONS for t in COMPOUNDS}
108    ).to_numpy(dtype=float)
109    deg = _lookup(DEG_PER_LAP, compound) * np.clip(1 + 0.02 * (track_temp - 35), 0.6, 1.6)
110    # Treaded tyres overheat and wear quickly on a dry track.
111    deg = np.where((condition == "dry") & np.isin(compound, ["intermediate", "wet"]), deg * 3, deg)
112    wear = deg * age + CLIFF_DEG_PER_LAP * np.maximum(0, age - _lookup(CLIFF_LAP, compound))
113    cold_hard = (compound == "hard") & (track_temp < 25)
114    return base - wear - 0.01 * cold_hard

117def initial_conditions(df, car=CAR):
118    """Translate scenarios into the physical inputs of the two-car model.
119
120    Parameters
121    ----------
122    df : pandas.DataFrame
123        Scenarios in the `overtake.features` schema.
124    car : CarParameters, optional
125
126    Returns
127    -------
128    dict
129        ``attacker`` and ``defender`` (`CarState`), corner-exit speeds
130        ``v0_a`` and ``v0_d`` (m/s), ``gap`` (s), ``length`` (m) and relative
131        tyre grip ``grip_a`` and ``grip_d``.
132    """
133    cond = df["track_condition"].to_numpy()
134    temp = df["track_temp_c"].to_numpy(dtype=float)
135    gap = df["gap_s"].to_numpy(dtype=float)
136    grip_a = tyre_grip(df["attacker_tyre"], df["attacker_tyre_age"], cond, temp)
137    grip_d = tyre_grip(df["defender_tyre"], df["defender_tyre_age"], cond, temp)
138
139    om = df["overtake_mode"].to_numpy(dtype=bool)
140    boost_a = df["attacker_boost"].to_numpy(dtype=bool)
141    boost_d = df["defender_boost"].to_numpy(dtype=bool)
142    speed_gain = df["top_speed_delta_kph"].to_numpy(dtype=float) / 3.6
143    # At fixed power, top speed scales with CdA^(-1/3).
144    cda_a = car.cda_m2 * (TOP_SPEED_REF_MPS / (TOP_SPEED_REF_MPS + speed_gain)) ** 3
145
146    attacker = CarState(
147        mu=car.mu_reference * grip_a,
148        cda_m2=cda_a,
149        deploy_share=np.where(boost_a, 1.0, STANDARD_MAP_SHARE),
150        energy_j=BATTERY_USABLE_J * df["attacker_battery"].to_numpy(dtype=float) / 100 + OVERTAKE_MODE_EXTRA_J * om,
151        overtake_mode=om,
152    )
153    defender = CarState(
154        mu=car.mu_reference * grip_d,
155        cda_m2=np.full(len(df), car.cda_m2),
156        deploy_share=np.where(boost_d, 1.0, STANDARD_MAP_SHARE),
157        energy_j=BATTERY_USABLE_J * df["defender_battery"].to_numpy(dtype=float) / 100,
158    )
159    # Corner speed scales with sqrt(grip); following closely costs grip (dirty
160    # air); a lap-time advantage is applied as a proportional speed advantage.
161    v0_d = EXIT_SPEED_MPS * np.sqrt(grip_d)
162    v0_a = (EXIT_SPEED_MPS * np.sqrt(grip_a * (1 - DIRTY_AIR_GRIP_LOSS * np.exp(-gap)))
163            * (1 + df["pace_delta_s"].to_numpy(dtype=float) / LAP_TIME_REF_S))
164    return {"attacker": attacker, "defender": defender, "v0_a": v0_a, "v0_d": v0_d, "gap": gap,
165            "length": df["run_length_m"].to_numpy(dtype=float), "grip_a": grip_a, "grip_d": grip_d}

168def closing_run(df, dt=TIME_STEP_S, method="rk4", car=CAR):
169    """Stage 1: integrate both cars along the run for every scenario.
170
171    Parameters
172    ----------
173    df : pandas.DataFrame
174        Scenarios in the `overtake.features` schema.
175    dt : float, optional
176        Integration time step, s.
177    method : {"rk4", "euler"}, optional
178    car : CarParameters, optional
179
180    Returns
181    -------
182    run : overtake.physics.RunResult
183        State at the braking point, including the deficit in seconds.
184    grip_a, grip_d : numpy.ndarray
185        Relative tyre grip of the attacker and defender.
186    """
187    ic = initial_conditions(df, car)
188    run = run_to_braking_point(ic["length"], ic["gap"], ic["v0_a"], ic["v0_d"], ic["attacker"], ic["defender"],
189                               car, dt=dt, method=method)
190    return run, ic["grip_a"], ic["grip_d"]

193def speed_trace(scenario, dt=TIME_STEP_S, car=CAR):
194    """Time history of both cars along the run for one scenario.
195
196    Parameters
197    ----------
198    scenario : dict
199        A complete scenario in the `overtake.features` schema.
200    dt : float, optional
201    car : CarParameters, optional
202
203    Returns
204    -------
205    pandas.DataFrame
206        Columns ``t`` (s), ``attacker_x``, ``defender_x`` (m, from the corner
207        exit), ``attacker_kph``, ``defender_kph`` and ``attacker_mj``,
208        ``defender_mj`` (electrical energy used), one row per step until the
209        defender reaches the braking point.
210    """
211    ic = initial_conditions(pd.DataFrame([scenario]), car)
212    y = np.array([[-ic["gap"][0] * ic["v0_d"][0]], [ic["v0_a"][0]], [0.0], [0.0], [ic["v0_d"][0]], [0.0]])
213    rows, t = [], 0.0
214    while y[3, 0] < ic["length"][0]:
215        rows.append([t, *y[:, 0]])
216        y = rk4_step(lambda s: two_car_rhs(s, ic["attacker"], ic["defender"], car), y, dt)
217        t += dt
218    trace = pd.DataFrame(rows, columns=["t", "attacker_x", "attacker_v", "attacker_e",
219                                        "defender_x", "defender_v", "defender_e"])
220    for who in ("attacker", "defender"):
221        trace[f"{who}_kph"] = trace.pop(f"{who}_v") * 3.6
222        trace[f"{who}_mj"] = trace.pop(f"{who}_e") / 1e6
223    return trace

226def outcome_parameters(df, run, grip_a, grip_d):
227    """Stage 2 inputs: effective deficit, execution noise and completion logit.
228
229    Parameters
230    ----------
231    df : pandas.DataFrame
232        Scenarios.
233    run : overtake.physics.RunResult
234        Output of `closing_run`.
235    grip_a, grip_d : numpy.ndarray
236        Relative tyre grip.
237
238    Returns
239    -------
240    deficit : numpy.ndarray
241        Deficit at the braking point including caution and defensive
242        positioning, s.
243    sigma : numpy.ndarray
244        Standard deviation of execution noise, s.
245    z0 : numpy.ndarray
246        Completion logit with zero margin.
247    """
248    cond = df["track_condition"].to_numpy()
249    skill_a = df["attacker_skill"].to_numpy(dtype=float)
250    skill_d = df["defender_skill"].to_numpy(dtype=float)
251    deficit = run.deficit_s + _lookup(CAUTION_S, cond) + 0.04 * (skill_d - 60) / 40
252    sigma = _lookup(EXECUTION_SD, cond) + 0.04 * np.clip((90 - skill_a) / 30, 0, 1)
253    z0 = (
254        0.5
255        + 1.2 * (skill_a - skill_d) / 40
256        + 25.0 * (grip_a - grip_d)
257        + _lookup(SEGMENT_LOGIT, df["segment"])
258        + _lookup(CONDITION_LOGIT, cond)
259        + _lookup(PASSABILITY, df["circuit"])
260        # A defender with energy left can fight back on the exit.
261        - 0.2 * df["defender_boost"].to_numpy(dtype=float) * df["defender_battery"].to_numpy(dtype=float) / 100
262    )
263    return deficit, sigma, z0

266def overtake_integral(deficit, sigma, z0, rule="gauss", n=16):
267    """Probability of an overtake given the stage-2 parameters.
268
269    Evaluates ``P = int_0^inf phi_sigma(u + D - L) logistic(z0 + k min(u, m)) du``
270    (``L`` = lunge range, ``k`` = margin logit slope, ``m`` = margin cap). The
271    tail beyond ``u = m`` has a closed form; the integral over ``[0, m]`` is
272    computed numerically.
273
274    Parameters
275    ----------
276    deficit, sigma, z0 : numpy.ndarray
277        From `outcome_parameters`.
278    rule : {"gauss", "simpson", "trapezoid"}, optional
279        Quadrature rule for ``[0, m]``: Gauss-Legendre with ``n`` nodes, or
280        composite Simpson / trapezoid with ``n`` intervals (``n`` even for
281        Simpson).
282    n : int, optional
283
284    Returns
285    -------
286    numpy.ndarray
287        Probability in [0, 1].
288    """
289    deficit, sigma, z0 = (np.asarray(a, dtype=float)[..., None] for a in (deficit, sigma, z0))
290    shift = deficit - LUNGE_RANGE_S
291
292    if rule == "gauss":
293        nodes, weights = np.polynomial.legendre.leggauss(n)
294        u = 0.5 * MAX_MARGIN_S * (nodes + 1)
295        w = 0.5 * MAX_MARGIN_S * weights
296    else:
297        u = np.linspace(0, MAX_MARGIN_S, n + 1)
298        h = MAX_MARGIN_S / n
299        if rule == "trapezoid":
300            w = np.full(n + 1, h)
301            w[[0, -1]] = h / 2
302        elif rule == "simpson":
303            if n % 2:
304                raise ValueError("Simpson's rule needs an even number of intervals")
305            w = np.where(np.arange(n + 1) % 2, 4.0, 2.0) * h / 3
306            w[[0, -1]] = h / 3
307        else:
308            raise ValueError(f"unknown rule {rule!r}")
309
310    density = np.exp(-0.5 * ((u + shift) / sigma) ** 2) / (sigma * np.sqrt(2 * np.pi))
311    body = (density * expit(z0 + MARGIN_LOGIT_PER_S * u) * w).sum(axis=-1)
312    tail = expit(z0 + MARGIN_LOGIT_PER_S * MAX_MARGIN_S) * (1 - ndtr((MAX_MARGIN_S + shift) / sigma))
313    return body + tail[..., 0]

316def probability(df, dt=TIME_STEP_S):
317    """Exact probability of an overtake for each scenario (physics + quadrature).
318
319    Parameters
320    ----------
321    df : pandas.DataFrame
322        Scenarios in the `overtake.features` schema.
323    dt : float, optional
324        ODE time step, s.
325
326    Returns
327    -------
328    numpy.ndarray
329    """
330    run, grip_a, grip_d = closing_run(df, dt=dt)
331    return overtake_integral(*outcome_parameters(df, run, grip_a, grip_d))

334def draw_outcomes(deficit, sigma, z0, rng):
335    """Play out one attempt per scenario by drawing the random variables.
336
337    Parameters
338    ----------
339    deficit, sigma, z0 : numpy.ndarray
340        From `outcome_parameters`.
341    rng : numpy.random.Generator
342
343    Returns
344    -------
345    numpy.ndarray of bool
346        True where the overtake stuck.
347    """
348    eps = rng.normal(0.0, sigma)
349    margin = eps - (deficit - LUNGE_RANGE_S)
350    sticks = rng.random(margin.shape) < expit(z0 + MARGIN_LOGIT_PER_S * np.minimum(margin, MAX_MARGIN_S))
351    return (margin >= 0) & sticks

354def monte_carlo_probability(df, n_runs, seed=1):
355    """Estimate each scenario's probability by replaying it ``n_runs`` times.
356
357    Used to check `probability`; its standard error is ``sqrt(p (1-p) / n_runs)``.
358    """
359    rng = np.random.default_rng(seed)
360    params = outcome_parameters(df, *closing_run(df))
361    repeated = [np.repeat(a[:, None], n_runs, axis=1) for a in params]
362    return draw_outcomes(*repeated, rng).mean(axis=1)

365def sample_scenarios(n, rng):
366    """Draw ``n`` varied race situations covering the whole input space.
367
368    Parameters
369    ----------
370    n : int
371    rng : numpy.random.Generator
372
373    Returns
374    -------
375    pandas.DataFrame
376        Scenarios in the `overtake.features` schema (no label).
377    """
378    cond = rng.choice(CONDITIONS, n, p=[0.75, 0.13, 0.12])
379    tyre_probs = {
380        "dry": [0.30, 0.38, 0.26, 0.04, 0.02],
381        "damp": [0.10, 0.10, 0.08, 0.57, 0.15],
382        "wet": [0.03, 0.03, 0.04, 0.48, 0.42],
383    }
384
385    def tyres():
386        out = np.empty(n, dtype=object)
387        for c in CONDITIONS:
388            mask = cond == c
389            out[mask] = rng.choice(COMPOUNDS, mask.sum(), p=tyre_probs[c])
390        return out
391
392    def battery():
393        # A full battery is a common race state (after a safety car or a
394        # harvesting lap), so 15 % of attempts start at exactly 100 %. Without
395        # this, 100 % sits at the edge of the training data, where the network
396        # was found to be least accurate (experiments.sensitivity).
397        return np.where(rng.random(n) < FULL_BATTERY_SHARE, 100.0, rng.uniform(0, 100, n))
398
399    seg = rng.choice(SEGMENTS, n, p=[0.55, 0.20, 0.15, 0.10])
400    gap = rng.uniform(0.05, 2.0, n)
401    # The gap at the detection point differs a little from the gap when the attack starts.
402    detection_gap = gap + rng.normal(0.0, 0.2, n)
403    return pd.DataFrame({
404        "track_condition": cond,
405        "segment": seg,
406        "circuit": rng.choice(CIRCUITS, n),
407        "attacker_tyre": tyres(),
408        "defender_tyre": tyres(),
409        "gap_s": gap,
410        "run_length_m": np.where(seg == "straight", rng.uniform(250, 1300, n), rng.uniform(50, 300, n)),
411        "attacker_battery": battery(),
412        "defender_battery": battery(),
413        "attacker_tyre_age": rng.integers(0, 41, n).astype(float),
414        "defender_tyre_age": rng.integers(0, 41, n).astype(float),
415        "track_temp_c": np.where(cond == "dry", rng.uniform(18, 55, n), rng.uniform(10, 32, n)),
416        "attacker_skill": rng.uniform(60, 100, n),
417        "defender_skill": rng.uniform(60, 100, n),
418        "top_speed_delta_kph": np.clip(rng.normal(0, 5, n), -15, 15),
419        "pace_delta_s": np.clip(rng.normal(0, 0.4, n), -1.5, 1.5),
420        "attacker_boost": rng.random(n) < 0.8,
421        "defender_boost": rng.random(n) < 0.5,
422        "overtake_mode": detection_gap <= 1.0,
423    })

426def generate_dataset(n, seed=0, chunk=20_000):
427    """Sample ``n`` scenarios and simulate one attempt each.
428
429    Parameters
430    ----------
431    n : int
432        Number of attempts.
433    seed : int, optional
434    chunk : int, optional
435        Scenarios integrated together; bounds memory and keeps arrays
436        cache-friendly (see ``experiments.performance``).
437
438    Returns
439    -------
440    pandas.DataFrame
441        Scenarios plus ``overtake`` (0/1 outcome) and ``p_true`` (exact
442        probability, for validation only - never a model input).
443    """
444    rng = np.random.default_rng(seed)
445    df = sample_scenarios(n, rng)
446    labels, p_true = np.empty(n, dtype=int), np.empty(n)
447    for start in range(0, n, chunk):
448        part = df.iloc[start:start + chunk]
449        params = outcome_parameters(part, *closing_run(part))
450        labels[start:start + chunk] = draw_outcomes(*params, rng)
451        p_true[start:start + chunk] = overtake_integral(*params)

 88    """Grip of a tyre relative to a new soft on a dry track.
 89
 90    Parameters
 91    ----------
 92    compound, condition : array_like of str
 93        Tyre compound and track condition per scenario.
 94    age : array_like

102    numpy.ndarray

def overtake_integral(deficit, sigma, z0, rule='gauss', n=16): 
267def overtake_integral(deficit, sigma, z0, rule="gauss", n=16):
268    """Probability of an overtake given the stage-2 parameters.
269
270    Evaluates ``P = int_0^inf phi_sigma(u + D - L) logistic(z0 + k min(u, m)) du``
271    (``L`` = lunge range, ``k`` = margin logit slope, ``m`` = margin cap). The
272    tail beyond ``u = m`` has a closed form; the integral over ``[0, m]`` is
273    computed numerically.
274
275    Parameters
276    ----------
277    deficit, sigma, z0 : numpy.ndarray
278        From `outcome_parameters`.
279    rule : {"gauss", "simpson", "trapezoid"}, optional
280        Quadrature rule for ``[0, m]``: Gauss-Legendre with ``n`` nodes, or
281        composite Simpson / trapezoid with ``n`` intervals (``n`` even for
282        Simpson).
283    n : int, optional
284
285    Returns
286    -------
287    numpy.ndarray
288        Probability in [0, 1].
289    """
290    deficit, sigma, z0 = (np.asarray(a, dtype=float)[..., None] for a in (deficit, sigma, z0))
291    shift = deficit - LUNGE_RANGE_S
292
293    if rule == "gauss":
294        nodes, weights = np.polynomial.legendre.leggauss(n)
295        u = 0.5 * MAX_MARGIN_S * (nodes + 1)
296        w = 0.5 * MAX_MARGIN_S * weights
297    else:
298        u = np.linspace(0, MAX_MARGIN_S, n + 1)
299        h = MAX_MARGIN_S / n
300        if rule == "trapezoid":
301            w = np.full(n + 1, h)
302            w[[0, -1]] = h / 2
303        elif rule == "simpson":
304            if n % 2:
305                raise ValueError("Simpson's rule needs an even number of intervals")
306            w = np.where(np.arange(n + 1) % 2, 4.0, 2.0) * h / 3
307            w[[0, -1]] = h / 3
308        else:
309            raise ValueError(f"unknown rule {rule!r}")
310
311    density = np.exp(-0.5 * ((u + shift) / sigma) ** 2) / (sigma * np.sqrt(2 * np.pi))
312    body = (density * expit(z0 + MARGIN_LOGIT_PER_S * u) * w).sum(axis=-1)
313    tail = expit(z0 + MARGIN_LOGIT_PER_S * MAX_MARGIN_S) * (1 - ndtr((MAX_MARGIN_S + shift) / sigma))
314    return body + tail[..., 0]

447    labels, p_true = np.empty(n, dtype=int), np.empty(n)
448    for start in range(0, n, chunk):
449        part = df.iloc[start:start + chunk]
450        params = outcome_parameters(part, *closing_run(part))
451        labels[start:start + chunk] = draw_outcomes(*params, rng)
452        p_true[start:start + chunk] = overtake_integral(*params)
453    df[LABEL] = labels
454    df["p_true"] = p_true
455    return df
