overtake.simulator

Simulator of one overtaking attempt under the 2026 rules.

No public dataset of 2026 overtakes records battery charge and Boost / Overtake Mode use, so the network is trained on attempts generated here. An attempt has two stages.

1. Closing (deterministic physics). overtake.physics integrates both cars from the corner exit to the braking point and returns the gap the attacker still has to close, D (s). Tyres set grip and corner-exit speed, the battery and Boost / Overtake Mode set the electrical power, the slipstream cuts the attacker's drag, and car performance differences shift exit speed and drag. Poor-weather caution and the defender's positioning add to D.

2. Execution (random). Driver execution varies from attempt to attempt, modelled as Gaussian noise eps ~ N(0, sigma) on the deficit. The attacker can lunge if D - eps is within LUNGE_RANGE_S; the margin is then u = eps - (D - LUNGE_RANGE_S). A lunge sticks with probability logistic(z0 + 5 min(u, 0.5)), where z0 collects driver ratings, braking grip, corner type, weather, circuit and the defender's remaining Boost energy.

Because the randomness is a single Gaussian variable, the exact probability of an overtake is a one-dimensional integral,

P = integral_0^inf  phi_sigma(u + D - LUNGE_RANGE_S) logistic(z0 + 5 min(u, 0.5)) du,

which probability evaluates by Gauss-Legendre quadrature on [0, 0.5] and in closed form beyond. This gives a ground truth to validate the network against. draw_outcomes (called by generate_dataset) instead draws the random variables, producing the 0/1 outcomes the network is trained on, exactly as real race data would look.

speed_trace records the time history of one attempt for plots, and monte_carlo_probability checks probability by replaying attempts.

Constants marked "estimate" are engineering judgements chosen to give plausible magnitudes, not values measured from F1 data.

101def tyre_grip(compound, age, condition, track_temp):
102    """Grip of a tyre relative to a new soft on a dry track.
103
104    Parameters
105    ----------
106    compound, condition : array_like of str
107        Tyre compound (one of `overtake.features.COMPOUNDS`) and track
108        condition (one of `overtake.features.CONDITIONS`), one per scenario.
109    age : array_like
110        Tyre age in laps.
111    track_temp : array_like
112        Track temperature, deg C. Hot tracks wear tyres faster; hard tyres
113        lose grip on a track below 25 C.
114
115    Returns
116    -------
117    numpy.ndarray of float
118        Relative grip per scenario: 1.0 for a new soft on a dry track, about
119        0.41-1.0 over the training ranges, and down to about 0.09 at the
120        accepted limits (80-lap soft on a wet track at 65 C or hotter). It is
121        positive for every input `overtake.features.validate` accepts. An
122        unknown compound or condition gives NaN (inputs are not validated here).
123    """
124    compound, condition = np.asarray(compound), np.asarray(condition)
125    age, track_temp = np.asarray(age, dtype=float), np.asarray(track_temp, dtype=float)
126    # GRIP[condition][compound] for every scenario at once, via a flattened (condition, compound) -> grip map.
127    base = pd.Series(list(zip(condition, compound))).map(
128        {(c, t): GRIP[c][t] for c in CONDITIONS for t in COMPOUNDS}
129    ).to_numpy(dtype=float)
130    # Wear rate changes by 2 % per deg C about a 35 C track (estimate), limited to 0.6-1.6 times the
131    # nominal rate; the limits bind below 15 C and above 65 C.
132    deg = _lookup(DEG_PER_LAP, compound) * np.clip(1 + 0.02 * (track_temp - 35), 0.6, 1.6)
133    # Treaded tyres overheat and wear three times as fast on a dry track (estimate).
134    deg = np.where((condition == "dry") & np.isin(compound, ["intermediate", "wet"]), deg * 3, deg)
135    # Linear wear, plus CLIFF_DEG_PER_LAP per lap beyond the compound's cliff lap.
136    wear = deg * age + CLIFF_DEG_PER_LAP * np.maximum(0, age - _lookup(CLIFF_LAP, compound))
137    # A hard tyre on a track below 25 C stays under its working temperature: -0.01 grip (estimate).
138    cold_hard = (compound == "hard") & (track_temp < 25)
139    return base - wear - 0.01 * cold_hard

142def initial_conditions(df, car=CAR):
143    """Translate scenarios into the physical inputs of the two-car model.
144
145    Parameters
146    ----------
147    df : pandas.DataFrame
148        Scenarios in the `overtake.features` schema. Not validated here: a
149        missing column raises ``KeyError`` and an unknown tyre or condition
150        gives NaN, so callers validate first (as `probability` and
151        `speed_trace` do).
152    car : CarParameters, optional
153        Physical parameters shared by both cars (default `CAR`).
154
155    Returns
156    -------
157    dict
158        ``attacker`` and ``defender`` (`overtake.physics.CarState`), corner-exit
159        speeds ``v0_a`` and ``v0_d`` (m/s), ``gap`` (s), ``length`` (m) and
160        relative tyre grip ``grip_a`` and ``grip_d``; arrays have one entry per
161        row of ``df``.
162    """
163    cond = df["track_condition"].to_numpy()
164    temp = df["track_temp_c"].to_numpy(dtype=float)
165    gap = df["gap_s"].to_numpy(dtype=float)
166    grip_a = tyre_grip(df["attacker_tyre"], df["attacker_tyre_age"], cond, temp)
167    grip_d = tyre_grip(df["defender_tyre"], df["defender_tyre_age"], cond, temp)
168
169    om = df["overtake_mode"].to_numpy(dtype=bool)
170    boost_a = df["attacker_boost"].to_numpy(dtype=bool)
171    boost_d = df["defender_boost"].to_numpy(dtype=bool)
172    # km/h -> m/s. Car differences are applied to the attacker only; the defender is the reference car.
173    speed_gain = df["top_speed_delta_kph"].to_numpy(dtype=float) / 3.6
174    # At fixed power P = 1/2 rho CdA v^3, so top speed scales with CdA^(-1/3); a car dv faster at
175    # TOP_SPEED_REF_MPS therefore has its CdA scaled by (v_ref / (v_ref + dv))^3.
176    cda_a = car.cda_m2 * (TOP_SPEED_REF_MPS / (TOP_SPEED_REF_MPS + speed_gain)) ** 3
177
178    # Boost deploys the full MGU-K limit, otherwise the standard map. Battery % -> J of usable
179    # energy; Overtake Mode adds OVERTAKE_MODE_EXTRA_J (0.5 MJ) on top for the attacker (2026 rules).
180    attacker = CarState(
181        mu=car.mu_reference * grip_a,
182        cda_m2=cda_a,
183        deploy_share=np.where(boost_a, 1.0, STANDARD_MAP_SHARE),
184        energy_j=BATTERY_USABLE_J * df["attacker_battery"].to_numpy(dtype=float) / 100 + OVERTAKE_MODE_EXTRA_J * om,
185        overtake_mode=om,
186    )
187    defender = CarState(
188        mu=car.mu_reference * grip_d,
189        cda_m2=np.full(len(df), car.cda_m2),
190        deploy_share=np.where(boost_d, 1.0, STANDARD_MAP_SHARE),
191        energy_j=BATTERY_USABLE_J * df["defender_battery"].to_numpy(dtype=float) / 100,
192    )
193    # Corner speed scales with sqrt(grip) (cornering limit v^2 / r = mu g). Following closely
194    # costs grip (dirty air): DIRTY_AIR_GRIP_LOSS right behind, decaying with an e-folding gap of
195    # 1 s (estimate). A lap-time advantage is applied as a proportional speed advantage.
196    v0_d = EXIT_SPEED_MPS * np.sqrt(grip_d)
197    v0_a = (EXIT_SPEED_MPS * np.sqrt(grip_a * (1 - DIRTY_AIR_GRIP_LOSS * np.exp(-gap)))
198            * (1 + df["pace_delta_s"].to_numpy(dtype=float) / LAP_TIME_REF_S))
199    return {"attacker": attacker, "defender": defender, "v0_a": v0_a, "v0_d": v0_d, "gap": gap,
200            "length": df["run_length_m"].to_numpy(dtype=float), "grip_a": grip_a, "grip_d": grip_d}

203def closing_run(df, dt=TIME_STEP_S, method="rk4", car=CAR, crossing="hermite"):
204    """Stage 1: integrate both cars along the run for every scenario.
205
206    All rows are integrated together as one vectorised system.
207
208    Parameters
209    ----------
210    df : pandas.DataFrame
211        Scenarios in the `overtake.features` schema. Not validated here (see
212        `initial_conditions`); `probability` validates first.
213    dt : float, optional
214        Integration time step, s (default `TIME_STEP_S`).
215    method : {"rk4", "euler"}, optional
216        Integrator; Euler is kept as the first-order baseline.
217    car : CarParameters, optional
218        Physical parameters shared by both cars (default `CAR`).
219    crossing : {"hermite", "linear"}, optional
220        Interpolation used to locate the braking point within the last step
221        (see `overtake.physics.run_to_braking_point`).
222
223    Returns
224    -------
225    run : overtake.physics.RunResult
226        State at the braking point, including the deficit in seconds.
227    grip_a, grip_d : numpy.ndarray
228        Relative tyre grip of the attacker and defender, one per row of ``df``.
229
230    Raises
231    ------
232    RuntimeError
233        If a scenario has not reached the braking point within 60 s of
234        simulated time (from `overtake.physics.run_to_braking_point`), for
235        example because an unknown defender tyre or track condition made the
236        defender's speed NaN.
237    ValueError
238        If ``crossing`` is not "hermite" or "linear".
239    KeyError
240        If ``method`` is not "rk4" or "euler", or a column of ``df`` is missing.
241    """
242    ic = initial_conditions(df, car)
243    run = run_to_braking_point(ic["length"], ic["gap"], ic["v0_a"], ic["v0_d"], ic["attacker"], ic["defender"],
244                               car, dt=dt, method=method, crossing=crossing)
245    return run, ic["grip_a"], ic["grip_d"]

248def speed_trace(scenario, dt=TIME_STEP_S, car=CAR):
249    """Time history of both cars along the run for one scenario.
250
251    Integrates the same equations as `closing_run` with RK4, one step at a time,
252    and records every step for plots (`overtake.experiments.speed_trace`).
253
254    Parameters
255    ----------
256    scenario : dict
257        A complete scenario in the `overtake.features` schema.
258    dt : float, optional
259        RK4 time step, s (default `TIME_STEP_S`).
260    car : CarParameters, optional
261        Physical parameters shared by both cars (default `CAR`).
262
263    Returns
264    -------
265    pandas.DataFrame
266        Columns, in order: ``t`` (s), ``attacker_x``, ``defender_x`` (m, from
267        the corner exit), ``attacker_kph``, ``attacker_mj``, ``defender_kph``,
268        ``defender_mj`` (speed in km/h and electrical energy used in MJ). One
269        row per step from t = 0 to the last step before the defender reaches
270        the braking point. The crossing is not interpolated (unlike
271        `closing_run`), so the last row can fall up to one step short (about
272        4.6 m at 330 km/h with the default step). ``attacker_x`` starts negative
273        because the attacker begins ``gap_s`` behind the defender, who starts
274        at the corner exit (x = 0).
275
276    Raises
277    ------
278    ValueError
279        If the scenario does not match the schema (`overtake.features.validate`).
280
281    Examples
282    --------
283    >>> from overtake.features import DEFAULTS
284    >>> trace = speed_trace(DEFAULTS)
285    >>> list(trace.columns)
286    ['t', 'attacker_x', 'defender_x', 'attacker_kph', 'attacker_mj', 'defender_kph', 'defender_mj']
287    >>> len(trace)
288    214
289    """
290    df = pd.DataFrame([scenario])
291    validate(df)
292    ic = initial_conditions(df, car)
293    # One-column state in the layout of overtake.physics.two_car_rhs: attacker x, v, e, then defender
294    # x, v, e. The defender starts at the corner exit, the attacker gap * v0_d metres behind it.
295    y = np.array([[-ic["gap"][0] * ic["v0_d"][0]], [ic["v0_a"][0]], [0.0], [0.0], [ic["v0_d"][0]], [0.0]])
296    rows, t = [], 0.0
297    # No time limit, unlike run_to_braking_point: validated inputs give the defender a positive
298    # exit speed, and engine power keeps it moving towards the braking point.
299    while y[3, 0] < ic["length"][0]:
300        rows.append([t, *y[:, 0]])
301        y = rk4_step(lambda s: two_car_rhs(s, ic["attacker"], ic["defender"], car), y, dt)
302        t += dt
303    trace = pd.DataFrame(rows, columns=["t", "attacker_x", "attacker_v", "attacker_e",
304                                        "defender_x", "defender_v", "defender_e"])
305    # Replace the raw columns with m/s -> km/h and J -> MJ, for plotting.
306    for who in ("attacker", "defender"):
307        trace[f"{who}_kph"] = trace.pop(f"{who}_v") * 3.6
308        trace[f"{who}_mj"] = trace.pop(f"{who}_e") / 1e6
309    return trace

312def outcome_parameters(df, run, grip_a, grip_d):
313    """Stage 2 inputs: effective deficit, execution noise and completion logit.
314
315    Each output has one entry per row of ``df``; together they are the
316    arguments of `overtake_integral` and `draw_outcomes`.
317
318    Parameters
319    ----------
320    df : pandas.DataFrame
321        Scenarios in the `overtake.features` schema (the same rows as ``run``).
322        Not validated here: an unknown category gives NaN.
323    run : overtake.physics.RunResult
324        Output of `closing_run`.
325    grip_a, grip_d : numpy.ndarray
326        Relative tyre grip of the attacker and defender (from `closing_run`).
327
328    Returns
329    -------
330    deficit : numpy.ndarray
331        Deficit at the braking point including caution and defensive
332        positioning, s.
333    sigma : numpy.ndarray
334        Standard deviation of execution noise, s.
335    z0 : numpy.ndarray
336        Completion logit with zero margin.
337    """
338    cond = df["track_condition"].to_numpy()
339    skill_a = df["attacker_skill"].to_numpy(dtype=float)
340    skill_d = df["defender_skill"].to_numpy(dtype=float)
341    # Weather caution, plus defensive positioning: a defender rated 60 adds nothing, one rated
342    # 100 adds 0.04 s (estimate).
343    deficit = run.deficit_s + _lookup(CAUTION_S, cond) + 0.04 * (skill_d - 60) / 40
344    # Lower-rated attackers are less consistent: a rating of 90 or more adds nothing to the spread,
345    # 60 or less adds 0.04 s (estimate).
346    sigma = _lookup(EXECUTION_SD, cond) + 0.04 * np.clip((90 - skill_a) / 30, 0, 1)
347    z0 = (
348        # Equal drivers and grip, a straight, a dry track, the generic circuit and no defender
349        # Boost energy: logistic(0.5) = 62 % at zero margin (estimate).
350        0.5
351        # A 40-point rating difference (the 60-100 training span) shifts the log-odds by 1.2 (estimate).
352        + 1.2 * (skill_a - skill_d) / 40
353        # Braking grip: the default 5-lap soft (0.991) against the 15-lap medium (0.9715) at 35 C
354        # adds 0.49 (estimate).
355        + 25.0 * (grip_a - grip_d)
356        + _lookup(SEGMENT_LOGIT, df["segment"])
357        + _lookup(CONDITION_LOGIT, cond)
358        + _lookup(PASSABILITY, df["circuit"])
359        # A defender with energy left can fight back on the exit: up to -0.2 with Boost and a
360        # full battery (estimate).
361        - 0.2 * df["defender_boost"].to_numpy(dtype=float) * df["defender_battery"].to_numpy(dtype=float) / 100
362    )
363    return deficit, sigma, z0

366def overtake_integral(deficit, sigma, z0, rule="gauss", n=16):
367    """Probability of an overtake given the stage-2 parameters.
368
369    Evaluates ``P = int_0^inf phi_sigma(u + D - L) logistic(z0 + k min(u, m)) du``
370    (``L`` = lunge range, ``k`` = margin logit slope, ``m`` = margin cap). The
371    tail beyond ``u = m`` has a closed form; the integral over ``[0, m]`` is
372    computed numerically.
373
374    Parameters
375    ----------
376    deficit, sigma, z0 : array_like
377        From `outcome_parameters`; any shapes that broadcast together.
378        ``deficit`` and ``sigma`` in s, ``z0`` in log-odds.
379    rule : {"gauss", "simpson", "trapezoid"}, optional
380        Quadrature rule for ``[0, m]``: Gauss-Legendre with ``n`` nodes, or
381        composite Simpson / trapezoid with ``n`` intervals (``n`` even for
382        Simpson). Simpson and trapezoid are kept for comparison.
383    n : int, optional
384        Number of Gauss-Legendre nodes, or of Simpson / trapezoid intervals
385        (default 16). With Gauss-Legendre, 16 nodes agree with a 200-node
386        reference to within 2e-15 (`overtake.experiments.quadrature`).
387
388    Returns
389    -------
390    numpy.ndarray
391        Probability in [0, 1], with the broadcast shape of ``deficit``,
392        ``sigma`` and ``z0`` (a NumPy scalar for scalar inputs).
393
394    Raises
395    ------
396    ValueError
397        If ``rule`` is unknown, or ``rule="simpson"`` with an odd ``n``.
398    """
399    # New trailing axis: each scenario is evaluated at every quadrature node along the last axis.
400    deficit, sigma, z0 = (np.asarray(a, dtype=float)[..., None] for a in (deficit, sigma, z0))
401    shift = deficit - LUNGE_RANGE_S  # eps = u + shift, from u = eps - (D - L)
402
403    if rule == "gauss":
404        # On [0, m], min(u, m) = u, so the integrand is smooth (the kink of min sits at the end
405        # point) and Gauss-Legendre converges fast. Map the nodes from [-1, 1] to [0, m]; the
406        # Jacobian m/2 scales the weights.
407        nodes, weights = np.polynomial.legendre.leggauss(n)
408        u = 0.5 * MAX_MARGIN_S * (nodes + 1)
409        w = 0.5 * MAX_MARGIN_S * weights
410    else:
411        u = np.linspace(0, MAX_MARGIN_S, n + 1)
412        h = MAX_MARGIN_S / n
413        if rule == "trapezoid":
414            # Trapezoid weights: h * [1/2, 1, ..., 1, 1/2].
415            w = np.full(n + 1, h)
416            w[[0, -1]] = h / 2
417        elif rule == "simpson":
418            if n % 2:
419                raise ValueError("Simpson's rule needs an even number of intervals")
420            # Composite Simpson weights: h/3 * [1, 4, 2, 4, ..., 2, 4, 1].
421            w = np.where(np.arange(n + 1) % 2, 4.0, 2.0) * h / 3
422            w[[0, -1]] = h / 3
423        else:
424            raise ValueError(f"unknown rule {rule!r}")
425
426    # Normal density phi_sigma of the execution noise at eps = u + shift.
427    density = np.exp(-0.5 * ((u + shift) / sigma) ** 2) / (sigma * np.sqrt(2 * np.pi))
428    body = (density * expit(z0 + MARGIN_LOGIT_PER_S * u) * w).sum(axis=-1)
429    # Beyond u = m the logistic is constant, so the tail is that constant times
430    # P(eps > m + shift) = 1 - Phi((m + shift) / sigma).
431    tail = expit(z0 + MARGIN_LOGIT_PER_S * MAX_MARGIN_S) * (1 - ndtr((MAX_MARGIN_S + shift) / sigma))
432    return body + tail[..., 0]  # [..., 0] drops the size-1 node axis of the tail

477def draw_outcomes(deficit, sigma, z0, rng):
478    """Play out one attempt per scenario by drawing the random variables.
479
480    Parameters
481    ----------
482    deficit, sigma, z0 : numpy.ndarray
483        From `outcome_parameters`, all of the same shape.
484    rng : numpy.random.Generator
485        Source of the execution noise and of the stick test: one normal and
486        one uniform draw per scenario.
487
488    Returns
489    -------
490    numpy.ndarray of bool
491        True where the overtake stuck, same shape as the inputs.
492    """
493    eps = rng.normal(0.0, sigma)
494    # Margin u from the module docstring; a lunge is possible when u >= 0.
495    margin = eps - (deficit - LUNGE_RANGE_S)
496    # Stick test drawn for every scenario (vectorised); the number of draws then does not depend
497    # on which scenarios can lunge, so the random stream is fixed.
498    sticks = rng.random(margin.shape) < expit(z0 + MARGIN_LOGIT_PER_S * np.minimum(margin, MAX_MARGIN_S))
499    return (margin >= 0) & sticks

367def overtake_integral(deficit, sigma, z0, rule="gauss", n=16):
368    """Probability of an overtake given the stage-2 parameters.
369
370    Evaluates ``P = int_0^inf phi_sigma(u + D - L) logistic(z0 + k min(u, m)) du``
371    (``L`` = lunge range, ``k`` = margin logit slope, ``m`` = margin cap). The
372    tail beyond ``u = m`` has a closed form; the integral over ``[0, m]`` is
373    computed numerically.
374
375    Parameters
376    ----------
377    deficit, sigma, z0 : array_like
378        From `outcome_parameters`; any shapes that broadcast together.
379        ``deficit`` and ``sigma`` in s, ``z0`` in log-odds.
380    rule : {"gauss", "simpson", "trapezoid"}, optional
381        Quadrature rule for ``[0, m]``: Gauss-Legendre with ``n`` nodes, or
382        composite Simpson / trapezoid with ``n`` intervals (``n`` even for
383        Simpson). Simpson and trapezoid are kept for comparison.
384    n : int, optional
385        Number of Gauss-Legendre nodes, or of Simpson / trapezoid intervals
386        (default 16). With Gauss-Legendre, 16 nodes agree with a 200-node
387        reference to within 2e-15 (`overtake.experiments.quadrature`).
388
389    Returns
390    -------
391    numpy.ndarray
392        Probability in [0, 1], with the broadcast shape of ``deficit``,
393        ``sigma`` and ``z0`` (a NumPy scalar for scalar inputs).
394
395    Raises
396    ------
397    ValueError
398        If ``rule`` is unknown, or ``rule="simpson"`` with an odd ``n``.
399    """
400    # New trailing axis: each scenario is evaluated at every quadrature node along the last axis.
401    deficit, sigma, z0 = (np.asarray(a, dtype=float)[..., None] for a in (deficit, sigma, z0))
402    shift = deficit - LUNGE_RANGE_S  # eps = u + shift, from u = eps - (D - L)
403
404    if rule == "gauss":
405        # On [0, m], min(u, m) = u, so the integrand is smooth (the kink of min sits at the end
406        # point) and Gauss-Legendre converges fast. Map the nodes from [-1, 1] to [0, m]; the
407        # Jacobian m/2 scales the weights.
408        nodes, weights = np.polynomial.legendre.leggauss(n)
409        u = 0.5 * MAX_MARGIN_S * (nodes + 1)
410        w = 0.5 * MAX_MARGIN_S * weights
411    else:
412        u = np.linspace(0, MAX_MARGIN_S, n + 1)
413        h = MAX_MARGIN_S / n
414        if rule == "trapezoid":
415            # Trapezoid weights: h * [1/2, 1, ..., 1, 1/2].
416            w = np.full(n + 1, h)
417            w[[0, -1]] = h / 2
418        elif rule == "simpson":
419            if n % 2:
420                raise ValueError("Simpson's rule needs an even number of intervals")
421            # Composite Simpson weights: h/3 * [1, 4, 2, 4, ..., 2, 4, 1].
422            w = np.where(np.arange(n + 1) % 2, 4.0, 2.0) * h / 3
423            w[[0, -1]] = h / 3
424        else:
425            raise ValueError(f"unknown rule {rule!r}")
426
427    # Normal density phi_sigma of the execution noise at eps = u + shift.
428    density = np.exp(-0.5 * ((u + shift) / sigma) ** 2) / (sigma * np.sqrt(2 * np.pi))
429    body = (density * expit(z0 + MARGIN_LOGIT_PER_S * u) * w).sum(axis=-1)
430    # Beyond u = m the logistic is constant, so the tail is that constant times
431    # P(eps > m + shift) = 1 - Phi((m + shift) / sigma).
432    tail = expit(z0 + MARGIN_LOGIT_PER_S * MAX_MARGIN_S) * (1 - ndtr((MAX_MARGIN_S + shift) / sigma))
433    return body + tail[..., 0]  # [..., 0] drops the size-1 node axis of the tail
